# 留学人生模拟器：统一写作与规则契约

本文是本设计包的共同接口。发生冲突时，以 `03_SYSTEMS_AND_PROBABILITIES.md` 的最终数值规则、`06_ENGINE_AND_DATA_CONTRACT.md` 的执行顺序为准；文案不能隐式改变规则。

## 产品边界

- 单人、中文、纯文字；从高中最后一年两次选择开始，经本科四年8节点，符合条件时增加1年（2节点）或2年（4节点）硕士阶段。默认一局6–9分钟，上限10分钟；全文仅可选展开。
- 每学期选择一次投入重心，处理一个主线事件；S2/S4/S6 推进支线槽 A，S3/S5/S7 推进支线槽 B。每局最多两条不同支线，每条三幕。S1、S8 无支线事件。
- 核心四属性：`money`（可动用资金）、`academics`（学业积累）、`career`（职业积累）、`wellbeing`（身心状态），均 0–100。资金是抽象单位，不对应真实货币。没有独立好感度、签证、背包、战斗、住房经营系统。
- 五种投入重心 ID：`STUDY`、`CAREER`、`CAMPUS`、`WORK`、`REST`。核心数值由系统文档统一定义，剧情作者不得另行设定日常收入、学费或行动成本。
- 开局提供三个家庭档案，每档包含经济条件、家庭期待、一项个人特质。经济条件与期待解耦，不暗示某种家庭必然幸福或某种人生更高级。
- 国家是美国，学校使用全国真实高校目录。高中准备与策略决定档次抽取概率，同档随机三个大学offer供选择；不自由指定学校。人物与具体事件原创，抽象数值和概率是游戏参数，不能冒充现实院校统计。目录、分档与来源见11。
- 全部本科专业合并成一个抽象学习方向，不实现专业列表。恋爱不作首版的独立关系系统；人物关系可出现在事件文案和经历回顾中。
- 本科与硕士结束时的毕业机会均有三种：`PHD`（本科直博/硕士后申博）、`LOCAL_JOB`（留美工作）、`HOME_JOB`（回国就业）。资格满足后按数值与经历算概率并一次抽签；玩家从拿到的机会中选择，也始终可以选择 `TRANSITION`（主动调整/过渡期）。四种最终结局家族；博士终点是进入博士项目，不模拟博士过程。
- 本科两种工作都未获得时，若学业与家庭延续资助满足条件，可选 `MASTERS`，继续 1 或 2 年的可玩硕士阶段。`MASTERS` 是中途路线，不是最终结局。硕士后不得再次进入硕士。已有博士机会也可选择符合条件的硕士路线，但接受博士即结束本局。

## 内容 ID 与事件结构

- 主线：`CORE_01` 至 `CORE_08`，`stage` 对应 1 至 8。
- 高中：`HS_01`、`HS_02`，`kind: "highschool"`、`node: 1|2`；没有学期资助、投入重心和必要开销。这两事件的数值变化带入本科，申请准备度仅在申请阶段使用。
- 六条支线：`RESEARCH`、`INTERNSHIP`、`FRIENDSHIP`、`FAMILY`、`REORIENTATION`、`CREATIVE`。事件 ID 为 `ARC_<支线名>_<1|2|3>`。
- 硕士事件：`MASTER_01` 至 `MASTER_04`，`kind: "masters"`、`node: 1..4`，省略 `stage`/`arc`/`beat`。1 年硕士依次使用 01、04；2 年使用 01、02、03、04。硕士不产生新支线，既有历史标记保留。
- 每个事件只有 A、B 两个选项；全部选项除资金不足外均可选择。每个事件至少有一个不消耗资金的选项。
- 每项事件数值变化绝对值不超过 8；单个选项四项数值绝对值之和不超过 16。不添加概率、延迟数值结算或额外状态条。
- 每个选项只设置一个唯一历史标记，固定为 `<事件ID>_<选项ID>`。标记只增不删。更高层的“科研经历”“作品经验”由系统从标记或投入计数推导，不重复存储同义变量。
- 支线第二、三幕可用 `callbacks` 引用同支线前幕标记；主线可引用此前主线标记。不得假定玩家选择了某个选项，也不得假定玩家必然拿到录取/工作。
- 硕士 callback 可以引用此前主线或硕士节点；`MASTER_04` 的正文必须在未经历 02/03 时仍然成立。`MASTER_04_A` 代表完成研究报告，`MASTER_04_B` 代表完成应用项目，两者都完成硕士课程要求。
- 每份事件文档使用一个 `json` fenced block，包含完整事件数组。不要添加 JSON 注释或尾逗号。字段如下，所有数值变化明确列出四项。
- 最终每事件还必须有 `summary`，每选项有 `shortResult`，每 callback 有 `shortText`。下方结构示例加入短字段；长文保留供展开阅读。

```json
[
  {
    "id": "CORE_01",
    "kind": "core",
    "stage": 1,
    "title": "示例标题（本对象仅说明结构，不属于事件库）",
    "summary": "默认显示的短事件。",
    "body": "事件正文。",
    "callbacks": [],
    "choices": [
      {
        "id": "A",
        "label": "选择 A",
        "effects": {"money": 0, "academics": 2, "career": 0, "wellbeing": -2},
        "setFlags": ["CORE_01_A"],
        "shortResult": "默认短结果。",
        "result": "选择后立即呈现的结果文案。"
      },
      {
        "id": "B",
        "label": "选择 B",
        "effects": {"money": 0, "academics": 0, "career": 0, "wellbeing": 2},
        "setFlags": ["CORE_01_B"],
        "shortResult": "另一个短结果。",
        "result": "另一个结果。"
      }
    ]
  }
]
```

支线对象使用 `kind: "arc"`、`arc: "RESEARCH"`、`beat: 1`，省略 `stage`。callback 格式：`{"ifFlag":"ARC_RESEARCH_1_A","text":"接在正文后面的条件回顾。","shortText":"默认短回响。"}`。展开模式按数组顺序追加全部匹配项，默认只显示数组中最后一个匹配项的短回响。作者按先前发生顺序编排 callbacks。没有匹配项时正文仍须独立成立。

## 文案与数值边界

- 默认摘要35–65中文字，短结果15–35字，短回响12–25字。可展开正文100–180字、长结果45–100字。每事件包含具体情境、两种可理解动机和可见后果。字数为呈现预算，不由运行时随意截断正文。
- 借助稳定的人物与地点形成连续性，避免把每个事件写成无关段子。每次决定可有得失，但不必强制所有选项等值。
- 拒绝把经济弱势、身心低落、回国、转向或暂时无工作写成人格失败。
- 不写赌博、货币化抽卡或付费重抽。开局随机和结局随机全部由可复现 seed 驱动。
- 所有数字是原型起始参数，必须通过模拟与真人试玩调整；不能把设计意图写成经过实测的结论。
