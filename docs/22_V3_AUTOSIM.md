# 第三版玩法：只选天赋和分点，其余自动模拟

日期：2026-10-12。用户试玩第二版后的要求：照《人生重开模拟器》来——玩家只在开局选天赋、分配点数，之后全部由系统自动模拟；中间会发生很多事、也有很多结局，都不需要玩家选择，一条条输出给玩家看。界面也参考它（用户给的参考站：remake.ovz.cc）。

本文与更早的文档冲突时以本文为准。保留不变的：四属性与截断、天赋与效果（`16` §1.2–1.3、`17`）、学期安排池与每学期四张（`16` §2、`18`）、主线槽与随机事件（`16` §3、`19`、`20`）、突发小事（`16` §4、`21`）、申请抽档与三校 offer（`13`）、支线分配、毕业资格与概率公式（`03`）、硕士续篇、`07` 的结局文案、`14` 的结局卡与图鉴。**变化的只有一件事：原来由玩家做的每一个选择，现在由系统按角色的倾向自动做。** 规则版本提升到 `3.0.0`。

## 1. 流程

`首页（立即重开）→ 十连抽天赋、选 3 张 → 分配 20 点 → 人生轨迹（自动模拟，分段输出）→ 人生总结 → 再次重开`

- 整局由 `seed`、选中的三张天赋、四项点数（以及继承的天赋，见第 6 节）完全决定。确认分点的那一刻，整局就已经算完；界面只是分段把它显示出来。
- 没有任何中途选择：事件选项、学期安排、选哪所学校、毕业去向、读不读硕士，全部自动。

## 2. 分配点数

四项：**家境、学业、职业、身心**。每项 0–10，总和必须等于可分配的总点数（基础 20）。出身不再抽经济档（家境由玩家分点决定）；家庭期待与个人愿望仍按 `16` §1.1 的 key 抽出来，只影响文案与结局卡。

| 点数 | 作用 |
|---|---|
| 家境 `f` | 开局资金 `20 + 4f`；每学期资助 `5 + f`。经济档（用于文案、`UR`、家庭支线权重）：`f ≤ 3` 为 LOW，`4–7` 为 MID，`≥ 8` 为 HIGH |
| 学业 `a` | 开局学业 `8 + 2a`；申请准备度 `+ a` |
| 职业 `c` | 开局职业 `2 + 2c` |
| 身心 `w` | 开局身心 `40 + 6w` |

可分配的总点数是 20 加上天赋的 `points`（见 7.2）。开局四属性 = 上表 + 三张天赋的 `initial`，再截断到 0–100。每学期资助 = `5 + f` + 天赋 `stipend`。准备度 = 基础 + `a` + 天赋 `readiness` + `HS_01` 加成。四项各 5 点时，开局约等于第一版的“有计划的支持”档。

点数还决定角色的倾向（第 3 节）：学业点高的人更常选学习类安排，身心点高的人更爱往校园生活里跑，家境低的人更在意钱。

## 3. 角色怎样自己做决定

所有决定都用 `draw01(seed, key)`，同样的开局永远得到同样的一生。

### 3.1 事件选项

```text
在意程度 v = { money: 1 + (10 - f)/5, academics: 1 + a/5, career: 1 + c/5, wellbeing: 1 + (10 - w)/5 }
若当前资金 < 本学期必要开销：v.money += 3
若当前身心 < 30：v.wellbeing += 3
score(选项) = Σ v[k] × 该选项实际会发生的变化[k]
preferred = 得分高的选项（相同取 A）
买不起的选项不能选；两项都能选时：draw01(seed, "auto:event:" + eventId) < 0.70 取 preferred，否则取另一项
```

高中事件没有必要开销，资金那一条不触发。

### 3.2 学期安排

在本学期给出的四张里，去掉买不起的，按类别加权抽一张（展示顺序累计，取第一张累计值严格大于 r 的）：

```text
STUDY  2 + a/2
CAREER 2 + c/2
CAMPUS 2 + w/2
WORK   1 + (10 - f)/4 + (资金 < 2 × 必要开销 ? 10 : 0) + (资金 < 必要开销 ? 10 : 0)
REST   1 + (身心 < 25 ? 8 : 身心 < 45 ? 3 : 0)
r = draw01(seed, "auto:plan:" + stage + ":" + term) × 权重之和
```

### 3.3 选校

`offers[pickIndex(seed, "auto:school", 3)]`。

### 3.4 毕业去向

```text
顺序（按个人愿望）：DISCOVERY → PHD, LOCAL_JOB, HOME_JOB
                  INDEPENDENCE → LOCAL_JOB, HOME_JOB, PHD
                  BELONGING → HOME_JOB, LOCAL_JOB, PHD
offered = 当前检查点已取得的机会，按上面的顺序；首选 = 顺序里的第一项

读硕士的意愿 p（仅本科、且有可选的硕士方案时才考虑）：
    一个机会都没有            → 0.75
    有机会，但首选那一路没取得 → 0.35（再读一轮，下次再争）
    首选已经取得              → 0
若 draw01(seed, "auto:masters") < p：读硕士
        （两个方案都可选时 draw01(seed, "auto:masters:years") < 0.5 取一年，否则两年；只有一个可选就取它）
否则若 offered 非空：draw01(seed, "auto:route:" + degree) < 0.06 → 过渡期（主动留白）；否则取 offered[0]
否则过渡期
```

**硕士资格在第三版放宽了**：不再要求“两种工作都没有取得”，只要求本科学业达到 55、预算够（`03` 第 5 节的其余条件不变）。原来那条是第一版为了控制范围加的限制；自动模拟里按它算，读硕士的局只有约 0.5%，硕士的内容几乎没人看得到。经典模式仍按原规则。

## 4. 中途结局

像《人生重开模拟器》里人生可能在任何一年结束一样，这一局也可能不走到毕业。中途结局是数据：`src/content/earlyEndings.json`，每条有触发条件 `when` 和每学期的触发概率 `chancePermille`（千分之几，1000 表示必然）。

**每个本科或硕士学期期末结算之后**，按数组顺序逐条检查（经典模式没有中途结局）：

```text
for ending in EARLY_ENDINGS:                      // 数组顺序
    if when 的每一项都满足（见下表）
       and draw01(seed, "early:" + ending.id + ":" + stage + ":" + term) < chancePermille / 1000:
        本局到此结束，结局为 ending
        break
```

`when` 里写了的每一项都必须满足，没写的不限制：

| 键 | 含义 |
|---|---|
| `stage` | 当前学段，`UG` 或 `MS` |
| `termMin`／`termMax` | 当前学期的范围（含两端） |
| `statMin`／`statMax` | 期末结算后的四属性下限／上限（如 `{"money": 30}`） |
| `countMin`／`countMax` | 累计安排次数的下限／上限（按类别） |
| `pointsMin`／`pointsMax` | 开局点数的下限／上限 |
| `flagsAll` | 必须全部拥有的历史标记 |
| `talentsAny` | 拥有其中任意一张天赋 |
| `shortfallStreak` | 到本学期为止，连续 n 个学期期末出现资金短缺 |
| `zeroWellbeingStreak` | 到本学期为止，连续 n 个学期期末身心为 0 |
| `schoolStates`／`schoolTiers` | 学校所在州的缩写、学校档次在列表里 |
| `aspirations` | 抽到的个人愿望在列表里 |

- 每条中途结局自带名称、吐槽、标题、正文、五年后一句、给玩家看的达成条件和提示，以及卡面等级 `tier` 与完结状态 `status`。
- 结局卡：等级取 `tier`（沿用该档的标签与类别，如“UR · 满配结局”），名称与吐槽用中途结局自己的；没有隐藏标签；组合写法照旧（如 `SR＋未完待续`）。`facts` 写触发它的真实数值。
- 中途结局没有毕业快照，也不产生毕业机会抽签。`07` 的四类终局文案不适用，显示中途结局自己的正文。
- 图册的“中途结局”一栏列出全部条目；中途结局同时也算解锁了对应的主线等级。
- 内容口吻：留学生圈子里自嘲的那些梗与刻板印象（打气、花花公子、豪车、代写、赌场、炒币、代购、小黑屋……），黑色幽默、短；写后果不写细节，不露骨，不把危险行为写得诱人。

## 5. 人生轨迹与总结

### 5.1 轨迹

引擎把整局整理成一段段“轨迹”，界面按顺序一段一段显示：

| 段 | 内容 |
|---|---|
| 高三 | 两张高中事件各一行 |
| 申请季 | 准备度、策略、抽中的档次、三所 offer；选了哪所 |
| 每个学期（大一上 … 大四下；硕一上 …） | 突发小事（如果有）、这学期的安排、主线槽事件、支线事件（如果有）；期末出现资金短缺时加一行 |
| 本科毕业／硕士毕业 | 三路机会各一行（概率与结果，或“准备尚不足”）；去向一行（接受了什么、读硕士、或过渡期） |
| 中途结局 | 一行 |
| 去向结局 | 毕业并确定去向后一行：“后来，人们叫你：湾区码农。” |

- 事件一行的写法：`〈事件标题〉` + 所选选项的名字 + 短结果。安排一行：安排的名字。每行附带实际的四属性变化（界面用小字显示）。
- 每段带上这一段结束时的四属性，界面顶部的四属性随显示进度更新。
- 学期的叫法：大一上、大一下、大二上 …… 大四下；硕一上、硕一下、硕二上、硕二下。

### 5.2 去向结局

走到毕业并确定去向之后，再给这段人生起一个更具体的名字：同样是留美工作，可能是“湾区码农”，也可能是“纽约打工人”。去向结局是数据：`src/content/endingFlavors.json`，每条属于一个去向（`route`），有条件 `when`（键与第 4 节相同，另可用 `transitionMode` 和结局卡等级 `tiers`；属性与次数取最终检查点的冻结快照）和权重 `weight`。

```text
candidates = 该去向下 when 全部满足的条目（数组顺序；每个去向恰好有一条没有条件的兜底，所以不会为空）
r = draw01(seed, "flavor:" + route) × 候选权重之和，依次累加取第一条累计值严格大于 r 的
```

结局卡的 `flavor` 就是它（名称、吐槽、一两句描述）；中途结局没有去向结局。去向结局不改变等级、隐藏标签和任何数值。图册增加“去向结局”一栏。

### 5.3 总结

显示：去向结局的名称、吐槽与描述（毕业结局）、结局标题与正文（毕业结局用 `07` 的短结局；中途结局用自己的正文）、结局卡、五年后一段、四属性的最终值与评价、学校与档次、本局三张天赋与点数分配、最终检查点的三路机会（毕业结局才有）。

属性评价按最终值：`0–19 见底`、`20–39 吃紧`、`40–59 普通`、`60–79 不错`、`80–94 出色`、`95–100 拉满`。

## 6. 继承天赋

总结页可以从本局的三张天赋里选一张“下次还能抽到”（可以不选）。下一局的十连抽里，第一张固定是它，其余九张按 `16` §1.2 照常抽（跳过与它相同的那张）。继承的天赋是下一局的输入之一，随存档保存；它不带到再下一局，除非再选一次。

## 7. 成就图册与天赋解锁

为了让人愿意一局一局玩下去（用户 2026-10-12 的要求）。这些都是跨局的进度，存在本机，与单局存档分开。

### 7.1 成就

成就清单在 `src/content/achievements.json`（id、名称、一句说明、档次 N／R／SR／SSR）。每局结束时由引擎的纯函数判定本局新得到哪些：有的看这一局的结果（去向、属性、安排次数、抽到的天赋、分点方式……），有的看累计进度（重开次数、已解锁的结局数……）。每条成就的判定条件写在引擎里，与清单里的说明一致。已得到的成就不重复计。

### 7.2 解锁稀有天赋

天赋池里一部分稀有天赋一开始是锁着的（`17_TALENTS.md` 里带 `locked: true` 的）。没解锁的天赋不会出现在十连抽里。

每局结束时抽一次：

```text
locked = 天赋池里还没解锁的锁定天赋（池内顺序）
chance = min(100, 20 + 20 × 本局新得到的成就数)        // 百分比
if locked 非空 且 draw01(seed, "unlock:roll") < chance / 100:
    解锁 locked[pickIndex(seed, "unlock:pick", locked.length)]
```

解锁结果显示在人生总结页。已解锁的天赋集合是下一局的输入之一（它决定十连抽的池子），随存档保存，所以同一份存档重新打开还是同一局。

新增一个天赋效果键 `points`：可分配点数的增减（基础是 20）。

### 7.3 图册

图册一页看全部跨局进度：结局（主线等级、隐藏结局、中途结局）、成就、天赋（已解锁的显示内容，没解锁的只显示稀有度与“未解锁”）。首页与总结页都能打开。它只是收藏册，不提供重抽、不联网。

## 8. 界面（参考《人生重开模拟器》）

- 居中的单栏，最大宽度约 30rem；按钮大而简单。
- **首页**：标题、一句话、`立即重开` 按钮；次级入口：图册（见 7.3）、指定种子。
- **天赋**：十张天赋各占一整行，按稀有度整行着色（N 灰、R 蓝、SR 紫、SSR 橙），点一下选中/取消，选满 3 张后可以下一步。
- **分点**：四项各一行，`−`／数值／`＋`，显示剩余点数；`随机分配` 按钮；下方实时显示按当前分配得到的开局四属性、每学期资助。点数用完才能开始。
- **人生轨迹**：顶部一行四属性；下面是轨迹列表，每段左侧是时间标签、右侧是这一段发生的事。点一下屏幕或按钮显示下一段；提供`自动播放`和`直接看结局`。到结尾出现 `人生总结` 按钮。
- **人生总结**：见 5.2；本局新得到的成就与新解锁的天赋；底部 `再次重开`，以及继承天赋的选择。
- 没有任何需要玩家做的中途选择，也没有可展开的长文。

## 9. 经典模式

不变（`16` §7）：显式操作、没有自动决定、没有中途结局、没有分点（经济档由调用方给定），继续用来和 Python 参考实现逐学期对拍。

## 10. 验收

- 同样的 seed、天赋、点数（与继承天赋）得到完全相同的一生；重新打开后显示的是同一局、同一进度。
- 任意合法的天赋与点数组合都能自动走到某个结局，不会卡住。
- 全部中途结局、去向结局、十档主线等级、十二个隐藏结局都能在自动模拟里出现（用大量 seed 与不同分点统计频率）。均衡分点（四项各 5）下中途结局合计在 30%–40%，单条不超过约 6%；极端分点可以明显更高。
- 分点确实改变倾向与结果：学业点高的局读博比例更高，家境低的局打工更多、更容易出现“钱烧完了”。
- 经典模式与 Python 参考实现逐学期一致。
- 界面全流程只有开局的两步需要玩家操作。
- 成就判定与天赋解锁是纯函数：同一局、同样的既有进度，得到同样的新成就与同样的解锁结果；锁定的天赋在解锁前绝不出现在十连抽里。
