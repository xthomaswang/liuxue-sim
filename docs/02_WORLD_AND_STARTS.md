# 世界、家庭与开局

## 1. 故事承诺

玩家从高中最后一年和自己的家庭开始，准备申请美国大学，再在本科四年逐渐决定：想把自己的能力、有限资源和精力放在哪里，以及毕业后愿意带着什么继续生活。满足系统条件时，可以继续一段一年或两年的硕士经历，再次面对博士项目与工作机会。

每一局的起点有差异，路上也不完全相同。出身会影响可承受的成本，但不会预先给人物贴上成功或失败的标签。故事关注的不是“留学值不值”，而是“在这个起点上，我做出了什么选择，后来怎样理解它”。

第一版从高中最后一年开始，以两个高中事件压缩准备与申请过程，之后进入本科八节点。本科结束时结算一次毕业机会；满足条件且选择继续硕士的玩家，再玩两个或四个硕士学期，之后第二次结算。五年后只是根据最后选择拼接的尾声，不再模拟五年。首版为纯文字游戏，所有场景、人物和结果都通过文本呈现，不依赖图片素材。主角姓名由玩家填写，可以留空并显示“你”。性别、民族、外貌不进入数值机制，也不需要玩家填写真实个人信息。

## 2. 世界与地点

**国家背景固定为美国，学校采用真实名称，人物与事件为原创虚构。** 后台学校池使用覆盖美国大学的目录，按照公开数据和产品定义作粗略分档，具体收录范围、分类方法与引用见 `11_SCHOOLS_AND_SOURCES.md`。Carnegie Mellon University、University of Washington、Arizona State University 只是可能的目录示例，不是固定的三个开局选项。学校主键使用 IPEDS UNITID 字符串，中文简称、城市与全名读取同一份数据；正文模板使用 `{{school.name}}`、`{{school.city}}`。分类用于生成相近档次的开局机会，不宣称存在唯一客观的学校等级。

学校之间共用事件；学校或分档是否产生数值影响，只能以最终系统文档明确列出的规则为准，剧情作者不得自行添加。首版不复制真实录取门槛、实际学费或各校特定学院政策。

学校选择发生在高中两个事件之后：系统根据 seed 确定的基础准备度、高中准备与申请策略标记确定一个 offer 档次，再从同一档次抽出三所不同学校，作为已拿到的本科 offer，玩家只能三选一。高中选择影响档次分布，不能提前保证具体学校或档次。四属性的高中改动继续保留到本科，但不重复计入申请准备度。准确申请公式见 `13_ADMISSIONS_AND_TEMPO.md`，学校目录与分档数据见 `11_SCHOOLS_AND_SOURCES.md`。首版不展开逐校申请材料、真实标准化考试或逐校录取抽签。

所选学校只记录本科背景。硕士阶段是学校未指定的美国项目，不默认原校保证续录，也不再次抽取学校；博士同样不锁定本校。真实项目长度随学校和专业而异，游戏使用统一的一年或两年硕士节奏，不宣称某所学校每个专业都提供相同学制；游戏概率不是学校真实录取率。

所有专业合并成一个抽象学习方向：玩家可以把它想象成自己感兴趣的专业；事件尽量使用资料分析、课程报告、小组项目、表达、协作等通用活动，不安排只有特定专业才能理解的考试题。学习中心、学生服务点、课程题目和活动安排均为综合虚构场景，不宣称真实学校存在对应课程、收费、职位或活动。

高中先使用家中的书桌与普通教室，入学后主要使用四个反复出现的文字场景：

| 地点 | 剧情用途 | 可复用的文字细节 |
|---|---|---|
| 宿舍的窗边书桌 | 收到家人消息、查看余额、整理材料、独处 | 台灯、行李箱、窗外雨、桌面纸张 |
| 图书馆与课程楼 | 课程反馈、合作作业、学业选择 | 公共长桌、打印机、走廊公告栏 |
| 校内学生服务点 | 校内学生岗位、学生项目、公共活动、职业练习 | 排班板、咖啡杯、纸箱、二手用品 |
| 校门与公共绿地 | 告别、归来、闲谈、回看生活 | 公交站牌、长椅、树影、远处灯光 |

这些是文字事件背景，不是可自由移动的地图，不要求插画、头像或场景图片。场景不产生额外经济或住房规则。具体校园介绍与城市差异从真实世界参考文件取用，不为所有学校统一添加海岸、港口、特定气候或特定交通工具。

故事里的有薪任务统一表示已由学校确认符合相应条件的校内学生岗位。课程合作项目也不等于可以任意在校外受雇。工作与实习的现实参考统一放在真实世界参考文件，不添加一套居留或许可经营系统。

## 3. 开局生成与选择

开局按“家庭三选一 → 个人愿望 → 高中准备 `HS_01` → 申请策略 `HS_02` → 同档次三个学校 offer 三选一 → 本科”推进。姓名、家庭与愿望可以同屏设置，目标在 45 秒内完成这部分设置；两个高中事件使用与大学相同的简洁事件界面，不做额外申请表单。学校目录仅用于后台抽样，前台不提供搜索全美学校后自由入学的入口。

系统使用本局 seed 生成三张完整家庭档案供玩家选择。三张分别固定 `LOW`、`MID`、`HIGH` 经济条件；每张的家庭期待和个人特质独立随机产生。不同卡片允许出现相同期待或特质，不需要因文案相似反复重抽。选定家庭后初始化四属性，高中事件直接修改这些属性，并原样带入本科，不在大学开学时重置。

确定家庭和个人愿望后完成两个高中事件，再按申请公式抽一个档次，并在该档内不放回抽三所学校；每张 offer 卡显示中文简称、城市和档次，玩家从中选择一所。此流程不反向修改家庭或特质抽样结果。高中阶段没有投入重心选择、家庭学期资助或期末开销，只执行事件效果与历史标记；本科阶段再开始正常的每学期循环。

一张卡片按以下顺序展示：经济条件与家庭期待名称 → 一段 40–70 字的组合短文 → 个人特质及规则说明 → 初始属性。经济条件与家庭期待的完整说明收进“家庭详情”折叠区。不得把家庭期待写成玩家已经同意的目标。

玩家选定家庭卡片后，可以填写名字，并从三个个人愿望中选择一个，然后进入高中事件。愿望仅用于叙事和结局回应，不改数值、不约束大学申请或毕业去向、不增加一条任务线。

选定前必须能看到完整属性和特质影响。不要设置“抽到后付费重抽”或把稀有度当作家庭身份；重开是正常的新一局。seed、属性、特质机制及选择阶段的具体规则，以 `03_SYSTEMS_AND_PROBABILITIES.md` 为准。

### 3.1 默认卡片短文

直接依次连接一条经济片段和一条期待片段，作为卡片唯一默认正文；个人特质单独显示，不追加到这段短文中。九种组合都在 40–70 字范围内。

| 类别 | ID | 默认短文片段 |
|---|---|---|
| 经济 | `LOW` | 家里的支持足够让你出发，但余量有限，额外支出需要认真安排。 |
| 经济 | `MID` | 家里已为正常学习和生活做好预算，额外尝试仍需要商量。 |
| 经济 | `HIGH` | 家里能承担更多试错成本，你有较宽裕的余地决定怎样使用支持。 |
| 期待 | `ACADEMIC` | 他们希望你继续深造，也担心你太早停下学习。 |
| 期待 | `STABILITY` | 他们希望你早些站稳，拥有可持续的工作和生活。 |
| 期待 | `AUTONOMY` | 他们愿意让你自己决定，也希望你遇到困难时说出来。 |

例如 `LOW + AUTONOMY` 默认显示：“家里的支持足够让你出发，但余量有限，额外支出需要认真安排。他们愿意让你自己决定，也希望你遇到困难时说出来。”

### 3.2 经济条件详情文案

| ID | 卡片名称 | 可直接使用的开局文案 | 叙事边界 |
|---|---|---|---|
| `LOW` | 精打细算的起点 | 家里为这次远行准备了很久，能够提供的余量有限。出发前，你把可能的开销列了好几遍。家人希望这段经历能为你打开一些机会，你也知道，每一次额外支出都值得先想一想。 | 经济紧张可以产生真实压力，但不默认家人欠债、患病或强迫玩家打工；这些不作为隐藏前提。 |
| `MID` | 有计划的支持 | 家里已经为你未来的正常学习与生活做了安排，额外的尝试仍需要商量。这份预算让远行变得可以计划，你也想在接下来的几年里慢慢弄清，哪些投入对自己真正重要。 | 不写成没有特点的“普通难度”；稳定计划与意外开销之间有自己的取舍。 |
| `HIGH` | 较宽裕的起点 | 家庭能承担更多试错成本，你不必在每次选择前先计算余额。准备申请时，你拥有较多余地，却还没有关于未来的答案。怎样使用这份支持，仍然要在日后的选择里慢慢形成自己的判断。 | 更充裕的资金确实有优势，不强行补一个人格缺陷或家庭不幸来平衡；成绩、工作和幸福仍不自动获得。 |

### 3.3 家庭期待详情文案

期待与经济条件独立组合，全部九种组合都必须有效。期待影响的规则只在系统文档定义，不新增可积累的“孝顺度”“满意度”或关系条。

| ID | 卡片名称 | 可直接使用的开局文案 | 家人的希望与担心 |
|---|---|---|---|
| `ACADEMIC` | 希望你继续深造 | 家人常说，既然走到了这里，就多学一点，看看自己能走多远。他们谈起未来时会先想到进一步学习，也担心你太早为了眼前的机会停下来。你可以理解这份期待，也可以逐渐形成不同的想法。 | 希望学习积累有延续；担心潜力没有得到尝试。不是所有交流都围绕成绩。 |
| `STABILITY` | 希望你早些站稳 | 家人最常问的是毕业以后怎样生活。他们希望你能找到一条稳定、能照顾自己的道路，遇到风险时也会习惯性地提醒。你知道这是关心，但“站稳”究竟意味着什么，你们未必一开始就有相同答案。 | 希望生活可持续；担心长期不确定。可以支持留在美国，也可以支持回国，不预设地理立场。 |
| `AUTONOMY` | 希望你自己决定 | 家人愿意把方向交给你，希望你在尝试之后做自己的决定。你拥有较大的选择空间，也会在拿不定主意时希望有人给出更明确的意见。这份信任能够支持你，但不会替你回答每一道难题。 | 希望玩家有自己的判断；担心支持不够具体。不等于永远无条件追加资金。 |

需要在后续普通主线中提及家庭时，默认只写“家人”“家里”，不假定双亲同住、特定职业或固定家庭成员。需要称谓的旁白可使用“屏幕另一端的家人”。首版不生成父母姓名、职业树、兄弟姐妹或遗产系统。

### 3.4 个人特质

六个 ID 与中文显示名固定为：`FOCUSED` 专注、`PRACTICAL` 务实、`OUTGOING` 善交际、`FRUGAL` 节省、`RESILIENT` 复原、`REFLECTIVE` 善反思。每张档案只有一项。准确说明、初始修正、行为修正全部引用 `03_SYSTEMS_AND_PROBABILITIES.md`，本文件不另行定义效果。

这些是行为倾向，不是道德等级，也不是精神健康诊断。特质不锁定任何选项；善交际的人可以独处，专注的人也可以优先经营职业。

### 3.5 玩家的个人愿望

| ID | 选择文字 | 开局回应 |
|---|---|---|
| `DISCOVERY` | 我想继续学习，看看自己能研究什么。 | 你还说不出未来的课题，但想先给好奇心留一些位置。 |
| `INDEPENDENCE` | 我想建立能力，逐渐在经济和职业上独立。 | 你希望有一天，作出决定时能更多依靠自己的积累。 |
| `BELONGING` | 我想找到一种能持续下去的生活和关系。 | 你想在陌生的地方慢慢生活，看看哪些人和事会成为牵挂。 |

愿望不会在中途强制玩家重新确认，也不会因为毕业选择不一致扣分。结局可以承认：“出发时，你最在意的是……。后来，这个愿望改变了形状。”

### 3.6 高中开局与入学旁白

高中开局默认短文：“高中最后一年开始了。家里已经认真讨论过留学的打算，你还没有拿到大学 offer。接下来，你需要决定怎样准备，以及愿意承担怎样的申请不确定性。”

高中开局展开旁白：

> 书桌上，一边是这学期的课程材料，一边是你刚开始整理的大学信息。家里已经讨论过出国的打算，也留下了一些暂时没有答案的问题。高中最后一年才刚开始，你还不知道会去哪里。现在能做的，是给接下来的准备找一个重点，再决定怎样申请。

选定 offer 后再显示大学入学旁白，此前不能插入 `{{school.name}}` 或 `{{school.city}}`：

> 到达 {{school.city}} 后，你终于在地图上找到 {{school.name}}。行李箱的轮子卡了一下，又继续向前。手机里留着家人临行前的消息，学校发来的邮件还没有全部读完。宿舍钥匙比想象中轻。你把它放进口袋，暂时还不知道四年后，会怎样记起今天。

默认入学短文：“你拖着行李来到 {{school.name}}。高中时的准备把你带到了这里。接下来这段生活，最后会去向哪里，仍要在选择中寻找。”上方完整旁白可展开阅读，不要求多点一次确认。

家庭说明和愿望回应在开局各显示一次即可，不把三段文字重复塞进每个事件。包括硕士在内，一局目标 6–9 分钟；所有事件默认使用 `summary`，选后使用 `shortResult`，完整 `body/result` 仅展开时显示。条件回响只默认显示最近一个命中的 `shortText`，全部长回响在展开区呈现。

## 4. 四位常驻人物

人物用于建立连续的生活感。遇见、帮助或拒绝他们，不产生隐形好感度；他们不负责无条件送工作、录取或资金。支线是否出现由支线槽决定，主线里见过某个人不等于已经完成其支线。

| 人物 | 身份与自己的目标 | 说话与行动习惯 | 剧情使用约束 |
|---|---|---|---|
| 林遥 | 来自故乡的同级生，习惯做预算，希望用设计作品找到自己的方向。 | 会先把时间和成本写下来，也喜欢观察海报、路牌和人的表情；常说“先试一个能做完的版本”。 | 可以陪伴，也会拒绝被当成免费救火队。不能默认和玩家同住、亲密或已经交换私人秘密。 |
| 艾达·洛文 | 美国本地同级生，参与社区口述史与校园电台，想在毕业前完成家乡声音纪录片。 | 常带着便携录音机，听完才提问；对自己的家乡也会有不熟悉和不满意的地方。 | 不扮演万能本地向导；录音、采访和合作都要征求对方同意。关系可以温暖，但首版不设恋爱路线。 |
| 许闻溪 | 玩家本科期间可能认识的高年级研究助理，研究公共空间与城市步行环境，正在权衡学术与公共服务岗位。 | 认真区分“我们观察到了什么”和“我们猜测什么”；愿意解释，也会说自己还不知道。 | 无法替玩家保证导师名额或录取。可以在对应支线中逐步认识，主线首次出场要自带身份说明。 |
| 周岚 | 校内学生服务点兼职排班负责人，也是白天工作、晚上修课的非传统年龄学生，希望毕业后办社区修理店。 | 重视准时交接、写清事项，忙完后才开玩笑；擅长把任务分成能执行的小步。 | 兼职机会来自明确任务，不以私交交换。对工作有边界，也拥有自己的学习压力和未来计划。 |

以上四人均为原创虚构人物，不影射学校的真实师生或雇员。“常驻”指跨文案可复用，不要求四人每局各出现三次。不要为达到出场配额添加事件。

## 5. 从高中到毕业的剧情节奏

本科的八个“学期”是统一的抽象故事节点，不代表每所学校真实只有八学期；采用 quarter 等学制的学校也使用同一叙事节奏。

| 节点 | 时间位置 | 本阶段要回答的问题 | 固定主线 |
|---|---|---|---|
| HS1 | 高中最后一年 | 怎样用有限时间为下一阶段准备？ | `HS_01` 书桌上的两种准备 |
| HS2 | 大学申请期 | 愿意怎样承担申请的不确定性？ | `HS_02` 递出申请之前 |
| S1 | 初到美国校园 | 我怎样在陌生环境里迈出第一步？ | `CORE_01` 箱子还没收好 |
| S2 | 第一年结束 | 第一次反馈之后，我要把剩余时间放在哪里？ | `CORE_02` 第一张成绩单之后 |
| S3 | 第二年秋 | 与别人一起做事时，我愿意承担什么？ | `CORE_03` 共同的桌子 |
| S4 | 第二年末暑假 | 一个完整的暑假，对现在的我最有价值的用途是什么？ | `CORE_04` 暑假的两份安排 |
| S5 | 第三年秋 | 当两边的生活都在继续，我怎样安排自己的位置？ | `CORE_05` 消息里的两座城市 |
| S6 | 第三年末申请前 | 面对未来，我愿意先把哪一部分准备得更充分？ | `CORE_06` 写下下一步 |
| S7 | 第四年秋 | 别人的消息接连出现时，我如何调整自己的节奏？ | `CORE_07` 走廊里的好消息 |
| S8 | 毕业前 | 离开这一阶段前，还有什么值得留下？ | `CORE_08` 归还钥匙以前 |

两个高中节点只处理事件，其间没有投入重心、学期资助和期末费用。申请结果与学校选择结束后，本科每一节点先选择投入重心，再处理主线；指定节点还处理一幕支线。剧情可以写“几个月过去”“暑假将近”，不额外扣除日历天数，也不引入每周行程表。

人生差异由家庭、个人特质、投入次数、两个支线及选择、毕业概率结果，以及是否继续硕士共同形成。本科主线提供所有人共有的时间坐标；硕士使用 `10_MASTERS_STORY.md` 的四个事件，其中一年路径只使用第一与第四个。硕士不再扩展新的支线槽或社交系统。

本科后没有拿到工作、学业与家庭承担能力满足规则的玩家，可以获得可选的硕士继续机会；准确资格、资金安排、学期数与再次申请概率以系统文档为准。继续硕士并不代表本科经历失败，也不保证两年后一定出现某种机会。符合博士申请规则的玩家可以本科直博，也可以硕士后申博；`PHD` 结局只表示进入博士项目，不表示取得博士学位。机会揭晓发生在本科或硕士的规定结算点，事件文案不能提前保证录取或就业。

## 6. 文风与范围

- 用具体、短小的生活细节承载情绪：一张改了很多次的排班表、一杯放凉的茶、一条停在输入框的消息。
- 两个选项都应有可理解的动机。休息不是懒惰，赚钱不是短视，研究不是自动更高尚，回国不是落败。
- 不用重大疾病、死亡、歧视或身份危机作为反复出现的随机惩罚；首版的戏剧张力来自有限资源与关系、能力、方向之间的取舍。
- 家庭差异不靠九条独立剧情树实现；组合文案和系统规则表达开局差异，通用事件承载共同处境。
- 新增国家、专业、恋爱对象、城市地图或不同入学年龄属于后续范围，不能作为当前故事完整性的前置条件。
