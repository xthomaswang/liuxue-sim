# 结局与人生回顾

结局有四个家族：`PHD`、`LOCAL_JOB`、`HOME_JOB`、`TRANSITION`。硕士是继续游戏的阶段，不是结局。结局由可枚举模块确定性组合，无新增抽签，无人生总分，无“好结局/坏结局”评级。

本文文案均为虚构角色的人生片段；真实大学仅是背景。收到工作机会不自动意味着满足入职许可、长期身份或移民条件，不新增签证玩法，也不替现实学校或雇主作承诺。

## 1. 输入、冻结和去向

从 `03_SYSTEMS_AND_PROBABILITIES.md` 取得：当前毕业检查点 UG/MS、冻结四属性、当前三机会结果、玩家最终去向、家庭经济/期待/特质、个人愿望、真实历史标记与事件结果、高中/本科/硕士阶段记录、申请快照、学校展示名。

- PHD 必须为当前检查点 OFFERED。UG 映射 `entryMode=undergrad_direct`；MS 映射 `entryMode=masters_entry`。
- LOCAL_JOB、HOME_JOB 必须为当前检查点对应的 OFFERED。
- TRANSITION 始终可选。当前任一机会为 OFFERED 时 `transitionMode=SELF_CHOSEN`，否则为 `NO_OFFER`。可读硕士但放弃，不等于有 OFFERED。
- 硕士毕业不能继续使用本科放弃的录取/工作。入学硕士期间不生成终局。
- 一次确认最终去向后保存所有输入，重看使用同一文案，不重新选择或重抽。

学校变量仅使用开局已经选择的 school displayName；不从学校名称推断专业、排名、资源、能力或录取优势。显示名按文本转义。

## 2. 默认短结局与完整回顾

首版从高中最后一年开始，一局即使读两年硕士也以 10 分钟内为目标；默认纯文字，生活决策总数为本科 24 次、一年硕士 28 次、两年硕士 32 次。默认正文约 120–180 中文字，长段落在“展开完整回顾”内，不能要求玩家连续阅读所有模块才能结束一局。

### 2.1 默认短结局

固定顺序：标题 → 学历/去向标签 → shortText → 一句关键经历 → 一句身心与资金近况 → 当前三路机会概率与结果 → 重玩/回看按钮。无资格项显示“准备不足”，有资格项的整数概率始终可见；详细分解折叠。

**shortText** 直接使用下表，不通过随机摘要生成。博士两种入口共享短正文，由独立学历标签明确区分。

| route / mode | shortText |
| --- | --- |
| PHD / 任一入口 | 你接受了博士录取，准备把这些年积累的问题带进下一段研究。离校文件旁边，是那本改过很多次的笔记。故事在博士入学这一刻停下，没有替你预先写完后面的学位。 |
| LOCAL_JOB | 你决定接受这次美国的工作机会，开始确认岗位、入职条件与生活安排。此前散在课表和项目里的准备，变成了具体的下一步。今后在哪里、怎样生活，仍有继续选择的空间。 |
| HOME_JOB | 你决定接受回国的工作机会，把笔记、项目和这几年形成的习惯一起带回去。熟悉的环境里仍有新的适应，留学经历也会在具体工作中慢慢显出不同的用处。 |
| TRANSITION / SELF_CHOSEN | 手里有可以接受的机会，你仍决定暂时不接下其中任何一个。你给生活留出一段空白，重新整理方向。答案还没有完全确定，但接下来怎样安排，你想再认真想一想。 |
| TRANSITION / NO_OFFER | 这一轮还没有拿到合适的录取或工作机会，你决定先进入一段过渡期。毕业到了，下一站尚未落定；你先安排日常，再整理可以继续尝试的方向。这一刻并不是对人生的最终评价。 |

学历/去向标签规则：

- PHD + UG：`本科直博 · 即将入学`。
- PHD + MS：`硕士后申博 · 即将入学`，旁边附 `一年制硕士` 或 `两年制硕士`。
- 非 PHD + UG：`本科毕业`。
- 非 PHD + MS：`一年制硕士毕业` 或 `两年制硕士毕业`。

关键经历优先取已完成的 MASTER_04；否则取实际最后发生的支线第 3 幕。极简开发夹具无支线时可回退 CORE_08；正式局均有两条支线。使用实际选项，不因概率高而编造报告或实习。句式固定为“你记得「{title}」里的决定：{label}。”标题超过 12 个 Unicode 码点、选项标签超过 18 个码点时各截取该长度并加省略号，完整文字仍在展开回顾里。

身心短句：DRAINED 为“毕业这阵子，你很疲惫，准备重新留出休息。”；STRETCHED 为“毕业这阵子，你的余量不多，想把节奏放稳些。”；STEADY 为“毕业这阵子，你还有一些安排日常与见人的余力。”

资金短句：NARROW 为“眼前资金紧张，需要把必要开销逐项安排。”；LIMITED 为“手里尚有一点缓冲，下一步仍需留意开销。”；BUFFERED 为“手里留有资金缓冲，可以从容一点安排下一步。”

两短句合为状态一段。正文长度目标包含 shortText、学历标签、关键经历与两短句；概率作为独立信息栏。界面控制行宽，但不删除决定性的信息来硬凑字数。

### 2.2 展开完整回顾的顺序

以下完整长文全部保留在展开区域，按以下顺序生成，各必选模块恰好一项：

1. 标题与**去向正文**：第 3 节六种合法变体中取一项。
2. **教育历程桥接**：第 4 节按 UG、MS_1Y、MS_2Y 取一项。
3. **毕业当下的状态**：先身心段，再资金段，使用第 5 节完整分桶。
4. **与开局愿望的对话**：第 6 节按 aspiration × 四家族取一项。
5. **与家里的对话**：第 7 节按 expectation × 路线组取一项。
6. **这几年记得的几件事**：第 8 节生成有事实依据的历史回顾。
7. **五年后的一页**：第 9 节按合法去向变体取一项。
8. 可展开的“这次机会如何形成”：显示冻结属性、投入计数、相关经历标记的中文名、当前三路资格/概率/结果。主视图不展示 raw roll；开发调试可展开查看。

展开后所有完整模块均可阅读；不因 money 或 wellbeing 为 0 丢失主结局，也不把获得的机会改写成死亡、退学或失去资格。身心/资金段明确描述“毕业这阵子”，不把当下的快照强行延续五年。

## 3. 去向标题与正文：六种合法变体

### PHD / undergrad_direct

**标题：把问题带进下一段研究**

你接受了博士项目的录取。离开本科校园时，你带走的除了毕业材料，还有几页改过很多次的笔记：有的结论被划掉，有的问题还没找到合适的问法。接下来，你将以博士生的身份继续学习和研究。这是进入博士的一刻，后面的题目、合作与生活安排，都还需要慢慢展开。

### PHD / masters_entry

**标题：再准备一次，然后走进研究**

你接受了博士项目的录取。硕士期间，你多了一段把问题做具体、把材料反复修改的经历，也更清楚什么样的研究值得自己继续投入。收拾离校的文件时，你把新的录取通知放在最后一页。接下来是博士入学；这段故事停在新的起点，没有替你写完未来的学位。

### LOCAL_JOB

**标题：把下一段职业起点放在美国**

你决定接受这次美国的工作机会。此前散在课表、项目和求职材料里的准备，终于有了一个具体的下一步。你开始逐项确认岗位、入职条件与生活安排，把“毕业以后做什么”从一整团问题，拆成眼前可以处理的几件事。这个决定并不替你规定今后一定在哪里生活。

### HOME_JOB

**标题：回去，开始另一段日常**

你决定接受回国的工作机会。打包行李时，有些东西留下了，有些带了回去：课程笔记、项目文件，还有这几年形成的做事习惯。回国后的工作会有新的节奏，你准备把在外面学到的东西放进具体的任务里。熟悉的语言与街道，也不会替你省去重新适应的过程。

### TRANSITION / SELF_CHOSEN

**标题：先留一点空白给自己**

手里有可以接受的机会，你仍决定暂时不接下其中任何一个。你给接下来的时间留了一点空白，整理作品、调整生活，或者再想一想自己愿意投入什么。拒绝现有选项不等于已经知道正确答案；你只是承认，当下还有一些事情需要由自己慢慢确定。

### TRANSITION / NO_OFFER

**标题：下一站，还在寻找中**

这一轮，你还没有拿到可以接受的录取或工作机会。毕业的日期到了，下一站却没有同时确定下来。你决定先进入一段过渡期，把生活安排好，再逐项整理要继续尝试的方向。这一页记录的是一个尚未落定的时刻，不是对你这几年努力的最终评价。

NO_OFFER 适用于零资格、全部申请未成，以及部分无资格/部分未成；机会详情分别列出真实原因，不把所有情况统称为“被所有学校和公司拒绝”。本科可读硕士但最终选过渡期时，正文仍成立，不暗示硕士路径从未存在。

| MS_1Y | 本科之后，你又用一年完成了硕士学习。时间没有替你保证某个结果，却给了你两段新的安排与尝试。 |

## 5. 毕业当下：状态模块

### 5.1 身心三态

分桶与投入效率阈值一致，但只是叙事读取，不再次改变数值。

| wellbeing | 状态 ID | 完整文案 |
| --- | --- | --- |
| 0–19 | `DRAINED` | 毕业这阵子，你已经很疲惫。收拾完一件事，总想再坐一会儿。下一步计划写在纸上，但把休息重新放进日程，同样是一件值得认真处理的事。 |
| 20–39 | `STRETCHED` | 毕业这阵子，你仍能把事情一项项处理完，只是余量不多。你开始更留意什么时候需要停一下，也想为下一段生活留出更能维持的节奏。 |
| 40–100 | `STEADY` | 毕业这阵子，你还有一些安排生活的余力。忙完离校的事情，也能留一点时间给散步、做饭或见人。未来仍有未知，但你不必今天就把所有答案找齐。 |

0 与 19 同属第一桶；20、39 属第二桶；40、100 属第三桶。不使用“抑郁症”“崩溃”等未被设定或诊断的表述，不推断永久健康状态。

### 5.2 资金三态

| money | 状态 ID | 完整文案 |
| --- | --- | --- |
| 0–9 | `NARROW` | 此刻能动用的钱已经不多。你把下一阶段的必要开销单独列了出来，尽量让安排有先后顺序。资金的紧张是眼前需要处理的条件，没有替你定义这几年生活的价值。 |
| 10–39 | `LIMITED` | 账面上还有一小段缓冲，但不足以让所有选择都不用考虑开销。你准备继续记着必要支出，也为下一步的变化留一点余地。 |
| 40–100 | `BUFFERED` | 账面上还保留着一段资金缓冲，让你有余地慢慢安排下一步。你知道这份余量有自己的来处，也知道它不会自动替你决定应该过什么样的生活。 |

这里只看毕业快照的可动用资金，不称为净资产、年薪或“实现财务自由”。NARROW + PHD/工作仍显示原去向；BUFFERED + TRANSITION 也不自动改成某种成功人生。

## 8. 核心历史回顾

不得从最终分数编造朋友、恋人、论文、实习、作品或家庭冲突。回顾使用玩家实际见过并选择过的事件。固定选择集合：

- 高中 HS_01、HS_02，保留准备方式与申请策略的真实选择。
- 本科 CORE_01、CORE_04、CORE_08。
- 两条已分配支线各自的第 3 幕，无论选 A/B 都纳入。
- 完成硕士时另加 MASTER_04；不虚构一年制未经历的 MASTER_02/03。

按高中 → 本科 → 硕士的真实时间顺序排序；高中按事件编号，本科/硕士按实际学期，同一期主线先于支线。因此本科终局七条、硕士终局八条。每条收起时展示实际 event.title 与“你选择了：{choice.label}”；展开后显示当时完整 choice.result。允许引用真实选择文本，不再随机生成一句可能冲突的总结。

所有条目通过唯一标记反查选项；一个事件必须恰有一个 A/B 标记，不能默认视为选 A。出现存档缺失/双选属于数据错误，应走引擎的恢复错误处理，不能编造经历以填满回顾。

事件回顾之前可另显示一条申请摘要：“当时的申请准备度为 {readiness}，你选择了{冲刺/稳健}方案，最后在三所 offer 中选择了 {schoolName}。”这不是额外事件，不修改回顾条数。U 显示“未分档”，不写“最低档”；准备度仅作过去的申请回顾，不成为毕业时的第五属性。

额外给一行确定性的投入概览，按 STUDY、CAREER、CAMPUS、WORK、REST 固定顺序显示各次数，名称使用“学习、职业准备、校园生活、校内兼职、休息整理”。不根据最多的一项给人贴“学霸”“社畜”等人格标签，不以行动次数比较人生价值。

硕士局可在机会详情里展开 UG 的旧结果，标题为“本科毕业时的选择”；正文明确这些机会已在进入硕士时放弃，避免误认为当前还能接受。

## 9. 五年后的一页

这是文学性的后记，不开启第二局、不执行新数值系统、不保证学位完成或持续取得某种身份。身心和资金的毕业快照不直接带入后记。

| 变体 | 后记 |
| --- | --- |
| PHD / undergrad_direct | 五年后，你还留着本科末尾的那本笔记。里面有些问题已经换了问法，有些曾经确信的判断被重新划掉。再翻到第一页时，你记起当年接受录取的自己：不知道研究会走向哪里，但已经愿意往前试一段。这里没有替你预先写下博士毕业，只留下继续学习与改变的空间。 |
| PHD / masters_entry | 五年后，你整理旧文件，看到本科毕业时的材料、硕士成果和那封博士录取通知。它们放在一起，并不像一条从来没有犹豫过的路线。你能认出每一次重新准备的痕迹，也更愿意承认，一段路的意义有时要走过之后才慢慢清楚。 |
| LOCAL_JOB | 五年后，最初的求职材料已经很久没有打开过。你在一些项目里学过新的做法，也重新调整过自己看重的事情。当年选择美国的那次工作机会，是故事中的一个起点；后来的工作与生活去向，留在那些逐渐变具体的日常里。 |
| HOME_JOB | 五年后，你偶尔还会想起留学时某一段普通的路。回国之后的工作与生活带来了新的问题，也让当年的一些经历有了新的用处。你已经不太愿意只用“留下还是回去”概括那几年，因为真正留下来的还有做事的方法与看世界的角度。 |
| TRANSITION / SELF_CHOSEN | 五年后，再想起毕业时暂时放下机会的那段时间，你已经不总追问另一个选择会不会更好。后来有过尝试，也有过调整，生活并没有因为那次停顿就停止发生。那一页空白没有自动给出答案，却允许后面的内容换一种方式写下去。 |
| TRANSITION / NO_OFFER | 五年后，你已经能够把毕业时的那段等待放回更长的时间里看。后来生活有过别的安排，也仍有未解的问题；当年没有同时到来的机会，没有替此后每一天作出决定。你记得那阵子并不轻松，也记得自己怎样把下一件能做的事慢慢做完。 |

博士后记不出现“顺利博士毕业”“已成为教授”等自动成就。工作后记不出现自动工作许可、绿卡、永久留美或固定高薪；过渡期也不以“后来一定逆袭”安慰玩家。

## 10. 界面与组合覆盖验收

主屏只展示第 2.1 节短结局，教育桥接、愿望、家庭、完整历史与五年后放入第 2.2 节可展开回顾，默认折叠；有资格机会的整数概率始终可见。结局底部仅保留“回看这次经历”“用新开局再玩一次”两个主要按钮，另在调试/分享区域提供复制 seed；不提供原地重抽录取按钮。

需要覆盖的输入维度：

- 六个合法去向变体：博士两种入口、两种工作、过渡期两种模式。
- 三个教育路径：UG、MS_1Y、MS_2Y；遵守博士入口与教育路径的一致性。
- 三个身心桶与三个资金桶，覆盖边界 0、19、20、39、40、100 及资金 9/10。
- 三种个人愿望和三种家庭期待。
- 回顾事件的真实 A/B 选择，包含研究/实习/作品支线选择 B，以及硕士结尾选择 A/B。

所有有效组合通过查表取得文字，不需要逐条手写笛卡尔积。验收重点是每个维度都有且只有一个适用模块、没有 undefined、没有 A/B 历史矛盾，以及低资金/低身心不会覆盖或撤销主结果。

至少人工读六个完整样例：本科直博且身心低/资金低；硕士申博；留美工作但开局愿望为 DISCOVERY；回国工作且资金宽裕；有工作机会仍主动过渡；本科无机会后读硕士、硕士仍无机会进入过渡。另检查本科可读硕士却选过渡的 NO_OFFER 文案。
