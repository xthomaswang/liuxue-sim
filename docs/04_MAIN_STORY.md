# 八个主线节点

## 主线的作用

本科主线让每一局都走完“抵达—尝试—投入—调整—告别”的四年。它提供稳定的时间坐标，家庭与两条支线则让玩家对相同场景产生不同理解。此处的告别是本科阶段收尾；符合条件且选择继续硕士的玩家，之后进入 `10_MASTERS_STORY.md`。事件本身只按 `effects` 修改属性，并记录唯一选择标记，不偷偷发放机会、关闭毕业去向或改变其他规则。

全部事件适用于任意家庭、个人特质、投入组合和支线组合。结果文案不假定玩家已经选过某项活动。条件回响只引用此前主线标记；命中时接在正文后，否则正文独立成立。

默认界面显示 `summary` 与最近一个命中 callback 的 `shortText`，选择后只显示 `shortResult`，不增加确认页。`body`、全部命中 callback 的 `text` 与完整 `result` 放入可选展开区。这样保留故事细节，同时使包含硕士的完整一局以 6–9 分钟为目标。

这些节点的戏剧张力逐步变化：前两节点侧重适应与可用资源，中间三个节点侧重协作、投入和两边生活，最后三个节点侧重准备、比较压力和如何告别。选择可以和玩家此前的方向一致，也允许改变方向，不设置“转向惩罚”。

## 连续性与结局使用

- `CORE_01` 的两个选择都表达安顿方式，不分别代表外向或内向身份。
- `CORE_02` 与 `CORE_04` 的有薪工作是明确完成的短任务，不等于获得实习标记或毕业工作；读书活动也不等于正式科研经历。系统只能按规定的历史标记推导资格。
- `CORE_05` 的归家或留校是一次阶段性安排，不替玩家决定毕业后是否回国。
- `CORE_06` 的材料准备不会关闭另一个毕业方向；`CORE_07` 的准备和休息也不会改变成功概率公式以外的隐含因素。
- `CORE_08` 结束后再统一计算本科毕业机会，并按系统规则展示可能的硕士继续选项。告别发生于本科阶段结束前，不代表玩家永久离开学校；不能在这段文案里提前写出工作、录取或五年后收入。
- 回顾页可直接使用事件 `title`、所选 `label` 与 `result`，不需要为十六个主线选择再写十六套隐藏结局。

## 内容验收

本文件包含且仅包含 `CORE_01` 至 `CORE_08` 八个事件，每个事件有 A/B 两个选择，阶段顺序唯一。全部选择均无资格门槛，唯一可用性限制为统一的资金规则。每个事件至少有一个 `money >= 0` 的选择；每个选项四项属性均显式列出，单项变化绝对值不大于 8，总绝对值不大于 16。每个选择只写入与事件和选项同名的一个历史标记。所有 callback 只指向更早阶段的主线标记。
