# 结局卡：等级、隐藏结局与留学人生图鉴

新增日期：2026-10-11。来源是用户提供的《留学人生模拟器》结局分级总表（“10 档主线等级＋12 种隐藏／特殊结局”，由网上流传的“留学生九大结局”等段子合并改写）。本文规定它在游戏里的确定性映射。

## 0. 与原设计的关系

- 原 `07_ENDINGS.md` 的文学结局（标题、短文、完整回顾、五年后）**原样保留**，结局卡是叠加在它上面的一层段子式评级，不改写、不替换任何一段正文。
- 原设计中“无人生总分、无好结局/坏结局评级”“最终文字不再做第二轮抽签”“不做成就树”等条款（`03` 第 8–9 节、`06` 第 7 节、`07` 开头、`08` 停止扩展条件），**在结局卡与图鉴这一层按用户 2026-10-11 的新要求作废**；其余范围限制不变。
- 结局卡不反向影响任何规则：不改四属性、不改机会概率、不改已取得的机会。
- 卡面必须带一句说明：**“等级按段子里的‘世俗爽度’排列，不是按人的价值排名。”** 稀有不等于幸福，隐藏不等于顶级，暂时卡关也不等于坏结局。

## 1. 一张卡由什么组成

`主线等级（恰好一个）＋隐藏标签（零到多个）＋完结状态（恰好一个）`，例如 `SSR＋H01＋HE`、`SR＋＋H05＋未完待续`、`R＋TE`。

卡片在玩家确认最终去向的同一原子操作里计算并写入存档，之后只读：回看、刷新、更新规则都不重算。

### 1.1 输入

全部取自**作出最终选择的那个毕业检查点**（本科直接结束取 UG，读过硕士取 MS）的冻结快照：

```text
A, C, MONEY, WB      = 冻结的 academics / career / money / wellbeing
S, J, CAMPUS, WORK, REST = 冻结的投入次数
R  = hasFlag(ARC_RESEARCH_3_A)     MR = hasFlag(MASTER_04_A)
offered   = 该检查点 OFFERED 的机会集合；n = 个数
allIneligible = 该检查点三路全部 INELIGIBLE
route, transitionMode（SELF_CHOSEN / NO_OFFER）
didMasters = 本局读过硕士
ugOffered  = 本科检查点 OFFERED 的机会集合（仅 didMasters 时有意义）
economy, aspiration, 已分配的两条支线
shortfallTerms = 全程出现资金短缺（shortfall > 0）的学期数
```

### 1.2 尾声抽签

结局卡允许使用以下抽签，全部走 `06` 的 `draw01(seed, key)`，同 seed 永远同结果。**不满足前置条件时不读取对应 key 的结果**（但 key 固定，互不错位）。

公开方式：`epilogue:status` 决定主线等级，只要前置条件满足（留美工作、`C>=70`、`WB>=40`），无论中没中都在“达成依据”里列出概率与结果；其余四个只关系到隐藏结局，**命中时才列出**，没命中不显示，避免把隐藏结局提前剧透。

| key | 含义 | 成功条件 |
|---|---|---|
| `epilogue:status` | 身份抽签（对应段子里的工签/身份线） | `roll < 0.35`（本科检查点）或 `roll < 0.50`（硕士检查点） |
| `epilogue:love` | 爱情支线 | `roll < 0.50` |
| `epilogue:dream` | 梦醒 | `roll < 0.03` |
| `epilogue:subscription` | 订阅制创作 | `roll < 0.25` |
| `epilogue:scam` | 被骗 | `roll < 0.06` |

这些概率是游戏参数，不是现实统计。

## 2. 主线等级：自上而下取第一个命中的

| 顺序 | 等级 | 名称 | 游戏内条件 |
|---:|---|---|---|
| 1 | `EX` 传奇结局 | 学术飞升 | `route=PHD` 且 `A>=95` 且 `S>=4` 且 `(R 或 MR)` |
| 2 | `UR` 满配结局 | 家族存档继承者 | `economy=HIGH` 且 `MONEY>=80` 且 `n=3`（三个机会全部取得；任意去向） |
| 3 | `SSR` 豪华大圆满 | 事业、身份双通关 | `route=LOCAL_JOB` 且 `C>=70` 且 `WB>=40` 且 `epilogue:status` 成功 |
| 4 | `SR＋` 精英结局 | 职业上岸，身份仍在加载 | `route=LOCAL_JOB` 的其余情况 |
| 5 | `SR＋` 精英结局 | 博士上岸，学位仍在加载 | `route=PHD` 的其余情况（本游戏补充的变体） |
| 6 | `SR` 优良结局 | 归国好岗 | `route=HOME_JOB` 且 `C>=85` |
| 7 | `R＋` 安稳结局 | 回家过好日子 | `route=HOME_JOB` 且 `WB>=40` 且 `MONEY>=20` |
| 8 | `R` 普通结局 | 普通毕业，普通上班 | `route=HOME_JOB` 的其余情况 |
| 9 | `BE` 翻车结局 | 学业／申请线崩盘 | `route=TRANSITION` 且 `NO_OFFER` 且 `(A<55 或 allIneligible)` |
| 10 | `D` 落差结局 | 阶层改变，但方向反了 | `route=TRANSITION` 且 `NO_OFFER` 且 `(didMasters 或 MONEY<10 或 shortfallTerms>=2)` |
| 11 | `N` 待机结局 | 毕业了，但下一关没开 | `route=TRANSITION` 的其余情况 |

每个合法结局恰好落入一档。等级 ID 为 `EX, UR, SSR, SR_PLUS, SR, R_PLUS, R, N, D, BE`；图鉴按 `EX → BE` 的固定顺序展示十档。

阈值按 4200 局自动模拟的频率调过一次：最初 UR 取 `MONEY>=70 且 n>=2`，在宽裕家庭里约四成都能达到（全体 13%），比 EX、SSR 常见得多；SR 最初取 `C>=70`，占了回国结局的四分之三。现行数值见上表与 `src/engine/constants.ts` 的 `CARD`。模拟用的是几种简单策略，不代表真实玩家分布，试玩后可再调。

原表把 EX 写成“成为教授”、SSR 写成“长期身份落定”。游戏不模拟博士过程和签证，所以 EX 只表示“带着拉满的学业与研究成果进入博士”，SSR 里的“身份”只是一次公开概率的尾声抽签；卡面文字不得声称已取得学位、教职、工作许可或永久身份。

## 3. 隐藏／特殊结局：命中的全部挂上

| 编号 | 名称 | 游戏内条件 |
|---|---|---|
| `H01` | 爱情支线通关 | `CAMPUS>=3` 且 `WB>=50` 且 `epilogue:love` 成功 |
| `H02` | 双地图生活 | `LOCAL_JOB ∈ offered` 且 `route=HOME_JOB` |
| `H03` | 跨职业转职 | `hasFlag(ARC_REORIENTATION_3_A)` 且 `route≠PHD` |
| `H04` | 留学中介闭环 | `didMasters` 且 `route ∈ {HOME_JOB, TRANSITION}` |
| `H05` | 流量转职 | `hasFlag(ARC_CREATIVE_3_A)` 且 `route≠PHD` |
| `H06` | 二周目翻盘 | `didMasters` 且 `ugOffered` 为空 且 `route≠TRANSITION` |
| `H07` | 主线任务被顶掉 | `aspiration=DISCOVERY` 且 `PHD ∈ offered` 且 `route ∈ {LOCAL_JOB, HOME_JOB}` |
| `H08` | 梦醒结局 | `epilogue:dream` 成功（无前置条件） |
| `H09` | 自我探索支线 | `REST>=3` 且 `CAMPUS>=2` |
| `H10` | 成人内容创作支线 | 两条支线之一是 `CREATIVE` 且 `route=TRANSITION` 且 `epilogue:subscription` 成功 |
| `H11` | 黑色幽默分支 | `MONEY>=30` 且 `epilogue:scam` 成功 |
| `H12`／`TE` | 真正结局：不再比较 | `WB>=50` 且 `(transitionMode=SELF_CHOSEN 或 (等级 ∈ {R, R＋, N} 且 REST+CAMPUS>=4))` |

改写说明：

- `H07` 原梗是“出国任务被取消”（竞赛太好直接拿到国内升学）。游戏里一定会出国，所以改成同一句吐槽能成立的情形：开局想做研究，博士机会也到手了，最后却接了工作。
- `H09` 原梗把造型与性别表达的变化写成“转职”。游戏不记录性别，这里只写“把造型、称呼和介绍自己的方式重新选了一遍”，不做好坏判断。
- `H10` 原梗直接列了 OnlyFans。游戏只保留“订阅制内容创作”这个梗名与一句吐槽，不写任何露骨内容；它是成人向恶搞分支，不是留学生画像。结局发生在本科毕业之后，主角已成年。
- `H11` 原梗含犯罪、毒品、暴力受害。游戏只保留“被骗”一种（接到自称大使馆的电话），不写暴力，也不扣任何数值。
- 隐藏结局只是卡面标签，不产生第二套剧情，也不修改 `07` 的正文。

## 4. 完结状态

| 顺序 | 状态 | 条件 |
|---:|---|---|
| 1 | `TE`（真正结局） | 命中 `H12` |
| 2 | `开放结局` | `route=TRANSITION` 且 `SELF_CHOSEN` |
| 3 | `HE` | 等级 ∈ `{EX, UR, SSR, SR, R＋, R}` |
| 4 | `未完待续` | 其余（`SR＋, N, D, BE`） |

组合写法：`等级标签`、各隐藏编号（按 H01…H11 顺序，`H12` 不单独写）、状态，用全角 `＋` 连接。等级标签 `SR＋`/`R＋` 本身带加号，所以会出现 `SR＋＋H05＋未完待续`，与原表示例一致。

## 5. 卡面与图鉴

- 结局页在短结局正文之后显示结局卡：等级标签与类别（如“SSR · 豪华大圆满”）、名称、一句吐槽、组合写法、隐藏标签列表（各带一句吐槽）、第 0 节那句说明。“达成依据”折叠：列出命中条件对应的真实数值／经历，以及用到的尾声抽签的概率与结果。
- **留学人生图鉴**：本机累计（单独的存储键，不随重开清空）。十档主线等级与十二个隐藏结局各一格，记录是否解锁、解锁次数、首次解锁的 seed。未解锁的主线等级显示等级标签与名称、隐去吐槽；未解锁的隐藏结局显示编号与“？？？”和一句提示。开局页与结局页都能打开图鉴。
- 图鉴只是收藏册：不解锁数值加成、不提供重抽、不联网、不排名。

## 6. 文案

卡面文案在 `src/content/endingCards.json`。名称与吐槽取自用户提供的总表（吐槽一栏原本就是改写），`SR＋` 的博士变体、`H07`/`H09`/`H10`/`H11` 的游戏内表述与全部“游戏内条件”说明为本项目补写。

## 7. 验收

- 任意合法终局恰好一个等级、恰好一个状态；隐藏标签零到多个且无重复。
- 十档等级与十二个隐藏结局都存在可构造的合法终局（用构造的快照逐一覆盖），并用整局模拟统计出现频率，EX/UR/SSR 不应成为常见结果。
- 同 seed 同选择得到同一张卡；卡片写入存档后回看不重算。
- 卡面不出现“已获得博士学位／教职／绿卡／工作许可”等原设计禁止的断言。
- 低资金、低身心不会改写 `07` 的主结局正文；结局卡不修改任何属性或机会。
