# 给 Claude 的实现交接

## 可直接复制的任务

> 请根据这个文件夹的 README 和 docs 完整实现《留学人生模拟器》。先阅读01/03/06/13/11以理解范围、数值、状态、申请与学校数据，再提取04/05/10/12中的事件JSON，读取02与07的开局和结局文案。首版纯文字，默认一局包含最长硕士线也控制在10分钟内。游戏从高中最后一年与家庭选择开始，申请后同一档次随机给三个真实美国大学offer，玩家只在其中选一所；本科四年八节点，本科无工作且满足成绩及家庭预算时可继续1–2年硕士，本科或硕士进入博士即博士结局。请实现完整闭环和必要验证，不增加本设计以外的系统。先将规则做成可测试纯函数，再接界面；不要先做装饰性页面代替可玩流程。全国学校目录与当年分档必须按11导入和校验，少量学校夹具仅可用于开发，不得声称已经支持全部美国大学。

## 项目与环境

- 本仓库根目录是用户指定的项目根。直接在此实现代码并保留docs，遵循适用的AGENTS.md；先检查已有文件，不覆盖用户工作。
- 建议技术栈：Vite、React、TypeScript，单页本地状态。若已有合理技术栈可沿用，但不因此改变功能范围。
- 使用 nvm，在项目放 `.nvmrc`（本机已有 Node 24 可作为起点），提交依赖锁文件。环境变量放项目 `.envrc`/`.env`，不能改全局 shell 配置。
- 不需要后端、用户账号、付费服务、数据库、LLM调用、图片生成、排行榜或云存档。
- 学校目录在构建前生成静态快照，运行游戏无需API密钥。导入原始大数据遵循机器的数据文件约定，不把大份原始数据和密钥提交进代码仓库。
- 本任务不授权自动部署、公开发布或推送含个人信息的内容。先把本地可运行版本做完整，再报告运行入口与检查结果。

## 实现顺序与每步产物

### A. 数据层

从四份事件文档唯一的JSON代码块提取32事件，不手工重打文案。提取短/长文、选项、effects、flags、callbacks，运行静态验证。建立学校catalog和ranking overlay的版本化结构。先用经过核验的少量学校夹具跑开发流程，同时明确生产完整目录仍待导入。

配置与文案分离。数值常量、申请权重和排名映射是数据，不散落在组件里。不要把故事中出现的“报告”“工作”字样自动解析成资格；资格只读取指定flag和计数。

### B. 规则引擎

实现纯函数：

- 创建seed、家庭候选与初始状态。
- 高中事件结算、申请准备度和档次概率。
- 同档学校offer无放回抽样。
- 学期资助、实际投入变化、事件资格、数值截断、期末费用及基础变化。
- 支线加权分配与两槽三幕推进。
- 冻结UG/MS快照，计算资格/整数概率、一次机会抽签。
- 硕士方案预算、入学费一次扣除、1年/2年节点映射。
- 最终路线与短/长结局模块组装。

先用事件数据运行几条真实轨迹，覆盖本科直接结束、一年硕士、两年硕士、本科博士和硕士博士。测试数学边界和状态转移，不给每一句静态文案写脆弱快照测试。

### C. 纯文字界面

最低组成：阶段标题、当前四属性、预计投入效果、当前短事件、两个选项、最近结果、继续按钮、折叠详情。学校offer只展示三张文本卡；不能出现前台全目录自由搜索入口。

高中申请默认展示准备度、策略与档次概率摘要，抽取后显示档次和三校。所有数据来自同一冻结抽取结果，切换详情不重抽。

每次选择立即生效，结果可在下一步骤上方保留。没有逐字动画、图片、音效、战斗、抽卡演出或强制等待。禁用的资金选项说明差额；概率信息不可藏到看完结局才出现。

毕业界面让玩家自己选择已取得的机会。未满足硕士条件时显示原因，不能只把按钮消失。硕士是继续游戏，不展示最终人生结算；PHD是最终路线，不进入额外博士玩法。

结局页默认短文，完整叙事与概率分解折叠。重新开始一键生成新seed；“重玩相同种子”可放次级入口。正在游戏时的重新开始需要防误触确认，结局后无需重复确认。

### D. 保存与可靠性

每个有效操作后保存。防重复结算需要reducer层校验，不能只依赖按钮disabled。存档至少记seed、版本、选择、flags、学校offer与选择、阶段、两次毕业快照。刷新后保持当前状态和已经抽出的结果。

保存异常时提示当前未保存并允许继续，不要误报已保存。存档损坏时可以重新开始，但不能随机拼接一局看似正常的历史。

### E. 全目录与最终验收

按11导入全国目录并生成覆盖报告，核对学校当前状态、校区身份、排名类别和年份。每个会被抽到的pool至少有3个不同ID。无排名资料的学校进入U独立池，不伪造“默认低档”；学校本身不直接改变毕业公式。

完成09列出的自动检查和真人时长测试。如果默认最长路线超过10分钟，先改呈现、重复确认和默认文案，不删掉用户指定的高中、硕士或博士分流来伪称完成。

## 停止扩展的条件

只要完整剧情可运行、结局有因果、概率和预算准确、存档可靠、学校目录符合覆盖验收、默认十分钟目标通过，就应收尾。不要顺手增加专业树、签证模拟、恋爱值、多人关系图、成就树、大学转学、二硕、博士过程或实时AI剧情。
