# 数值系统与机会概率

本文规定首版唯一有效的数值规则。所有数字均为**待调的原创原型参数**，不代表真实国家、大学或就业市场的统计概率。首版从高中最后一年两次事件开始，之后有本科 8 学期，以及条件满足后可选的 1 年/2 年硕士续篇；博士是“进入博士”的终点，没有博士经营阶段。地点为美国、真实大学目录及粗分档见学校目录文档。高中申请由 `13_ADMISSIONS_AND_TEMPO.md` 根据一次性准备度和策略抽取 tier，再给出同档三所大学 offer，由玩家选择一所。学校和 tier 字段只改变背景展示，全部共用本规则，不直接修改属性或机会概率。WORK 仅表示校内兼职，不暗指未经批准的校外就业；工作机会不自动代表工作许可或移民身份。制度说明见 11。

## 1. 属性、取整与状态边界

| ID | 展示名称 | 含义 |
| --- | --- | --- |
| `money` | 可动用资金 | 当下可支配的抽象资金，不对应真实货币或净资产。 |
| `academics` | 学业积累 | 学习、研究和表达的累计准备。 |
| `career` | 职业积累 | 实践、作品和求职准备的累计积累。 |
| `wellbeing` | 身心状态 | 当前休息余量与主观负担，不是医学诊断。 |

四项均为 `[0,100]` 内的整数。`clamp(x,lo,hi)=min(hi,max(lo,x))`；每次应用完整变化向量，四项同时更新再各自截断。正数半入为 `floor(x+0.5)`，不使用银行家舍入。不存超过上限的隐藏数值，不结转低于 0 的负值，不把一种属性的溢出转给另一种。

身心 0 **不会结束游戏、禁止选择或引发死亡/退学**。玩家仍可以休息、推进故事和毕业。低身心只通过第 3 节公开的投入效率影响后续积累；不会再额外扣毕业概率或随机追加疾病。

`focusCounts` 五项从 0 开始，每次确认投入只对一项加 1。高中两张事件不增加计数。总和在本科毕业为 8，一年硕士结束为 10，两年硕士结束为 12。加上事件选择，生活决策总数分别为 24/28/32；家庭、愿望、选校等菜单选择另计。所有历史标记只增不删，重复渲染或恢复存档不重复应用效果。

## 2. 开局

### 2.1 经济条件

下表是**高中事件开始前**的初始值。HS_01、HS_02 的实际效果直接保留到本科，进入 UG S1 不重置四属性。高中没有资助、投入、固定费用或基础学期成长；表中的每学期资助从本科 S1 才开始。

| economy | 展示名称 | 初始 money | 每学期资助 | 初始 academics | 初始 career | 初始 wellbeing |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| `LOW` | 预算紧一些 | 28 | 6 | 18 | 12 | 70 |
| `MID` | 有一定支持 | 42 | 10 | 18 | 12 | 70 |
| `HIGH` | 资金较宽裕 | 56 | 14 | 18 | 12 | 70 |

固定必要开销每学期 12；节俭特质为 11。每学期开始到账资助，学期末扣开销，本学期兼职可以支付本学期开销。S1、S8、硕士所有学期均照常到账并结算；硕士延续相同资助档。资金达到 100 后溢出舍去。

经济档与家庭期待、个人特质独立。资金宽裕不直接提高机会概率，预算少不降低行动基础收益，也不暗示家庭不幸福。

### 2.2 家庭期待

| expectation | 名称 | 规则影响 |
| --- | --- | --- |
| `ACADEMIC` | 希望学有所成 | 仅影响开局与结局家庭对话。 |
| `STABILITY` | 希望生活安稳 | 同上。 |
| `AUTONOMY` | 希望你自己决定 | 同上。 |

家庭期待不修改属性、资助、事件资格、硕士费用或机会概率。不设置“孝顺值”，不因改变去向惩罚；事件中明示的属性效果仍正常发生。

### 2.3 六种个人特质

每个档案一项特质，整局不更换、不叠加、不升级。

| trait | 名称 | 完整规则效果 |
| --- | --- | --- |
| `FOCUSED` | 容易进入专注 | `STUDY` 基础学业变化额外 +2。 |
| `PRACTICAL` | 边做边学 | `CAREER` 基础职业变化额外 +2。 |
| `OUTGOING` | 愿意主动搭话 | `CAMPUS` 基础职业变化额外 +2。 |
| `FRUGAL` | 很会安排开销 | 每学期必要开销 12 改为 11；事件花费、硕士一次性费用不变。 |
| `RESILIENT` | 有自己的缓冲办法 | 投入重心的负身心变化少扣 2，使用 `min(0,baseDelta+2)`；不减免事件、学期基础消耗或资金短缺压力。 |
| `REFLECTIVE` | 习惯留白整理 | `REST` 基础学业额外 +1、身心额外 +3。 |

特质先加到投入向量，再计算低身心效率，最后一次应用并截断。`REFLECTIVE` 的 REST 在效率折减前为学业 +2、身心 +18。

### 2.4 个人愿望

选中家庭档案后独立选择 `aspiration`，只改变结局回应，不改变概率；不按家庭期待自动选择。

| ID | 选项文案 |
| --- | --- |
| `DISCOVERY` | 我想继续学习，弄明白自己关心的问题。 |
| `INDEPENDENCE` | 我想建立自己的职业与经济独立。 |
| `BELONGING` | 我想找到能安顿下来、与人相处的生活。 |

首版不修改中途愿望；结局承认生活可以与开局计划不同，不把改变写成失败。

## 3. 五种投入与低身心效率

每学期投入一次，五项始终可选。常规投入无资金支出，基础成本已经包含于固定开销。

| focus | 名称 | money | academics | career | wellbeing |
| --- | --- | ---: | ---: | ---: | ---: |
| `STUDY` | 把时间留给学习 | 0 | +11 | +1 | -7 |
| `CAREER` | 为工作做准备 | 0 | +2 | +10 | -6 |
| `CAMPUS` | 参与校园生活 | 0 | +3 | +4 | +6 |
| `WORK` | 校内兼职补贴开销 | +12 | +1 | +3 | -7 |
| `REST` | 留时间休息整理 | 0 | +1 | 0 | +15 |

根据**选择投入前**的 wellbeing 确定效率：

| wellbeing | 乘数 | UI 说明 |
| --- | ---: | --- |
| 40–100 | 1.0 | 状态足够，积累正常。 |
| 20–39 | 0.8 | 最近有些疲惫，本次学习与职业积累按 80% 计算。 |
| 0–19 | 0.6 | 已经很疲惫，本次学习与职业积累按 60% 计算。 |

只有投入向量的**正 academics/career** 经特质加成后乘系数并半入。money 与 wellbeing 不折减，事件和学期基础变化也不折减。整数实现可用 `e=10/8/6; result=floor((positiveDelta*e+5)/10)`。

例：身心 19、FOCUSED、STUDY：学业 `(11+2)*0.6=7.8` 半入为 +8，职业 `1*0.6` 半入为 +1，身心 -7。REST 的恢复在选择后发生，不反过来改变本次效率。界面必须预览特质与效率后的实际效果，避免出现隐藏折减。

## 4. 每学期执行顺序

本科 S1–S8：每期一张对应主线 CORE_01–CORE_08。S2/S4/S6 推进槽 A 的三幕，S3/S5/S7 推进槽 B 的三幕；S1/S8 无支线。硕士每期一张硕士事件，无新增支线。

1. 发放资助，立即截断 money 上限；显示本期待付必要开销。
2. 选择投入：记录计数，合并特质，按选择前身心处理效率，应用向量。
3. 选择主线事件，原子地检查花费、应用效果、保存唯一标记。
4. 若本科本期安排支线，选择支线事件并保存结果。
5. 扣必要开销并处理短缺，见下节。
6. 统一应用基础学期变化：`money:0, academics:+2, career:+1, wellbeing:-3`。
7. 保存并显示本期账目与四属性快照；下一学期或毕业机会结算。

每步完成后截断属性，不能将一学期所有变化相加后只截断一次。例如身心 99，经 +6 后为 100，之后 -8 为 92，不是 97。资助、投入和结算都必须有幂等阶段记录，刷新不重复获得。

### 4.1 事件花费

选项 money 为负时，当前资金必须不少于花费。检查不预扣期末费用，但 UI 显示预计结算余额。钱不足时禁用并解释“需要 N，当前 M”；每张事件必须至少有一个不消耗资金的选项。其他三属性扣到 0 不禁止选择。

事件整项原子执行，不能先扣学业再发现资金不足；不足时全部不执行。事件不使用投入效率或特质加成。

### 4.2 资金短缺

```text
cost = trait == FRUGAL ? 11 : 12
shortfall = max(0, cost - money)
money = max(0, money - cost)
shortfallStress = shortfall == 0 ? 0 : 6 + ceil(shortfall / 3)
wellbeing = clamp(wellbeing - shortfallStress, 0, 100)
```

随后仍执行基础学期变化。短缺统一解释为通过紧急缓冲与临时压缩安排度过本学期，对应协调与不确定性带来的身心消耗。不实现贷款、债务利息、永久惩罚或援助机构经营。记录本期 shortfall，不另外增加状态条；下期正常到账。

例：结算前钱 5、身心 20、成本 12，短缺 7，额外压力 9；必要开销后钱 0、身心 11；再加基础变化，身心 8、学业 +2、职业 +1。身心已为 0 仍可继续。

## 5. 本科后的一年/两年硕士续篇

本科 S8 全部结算后，先冻结 UG 快照并一次揭晓 PHD、LOCAL_JOB、HOME_JOB 三种机会，再展示可选路径。MASTERS 是继续可玩的教育阶段，不是第五种终局。

### 5.1 开放条件

硕士两方案都必须满足：

- 当前毕业检查点为 UG，尚未读过硕士。
- `LOCAL_JOB` 与 `HOME_JOB` 均不是 OFFERED；无资格或申请未取得机会都算没有工作机会。
- UG 快照 `academics >= 55`。
- 对该方案分别通过下表的资金资格。

本科已获得 PHD 时也可以放弃该机会、选择符合条件的硕士；本科取得任一工作机会时，首版不开放硕士，即使玩家主观不想接受这份工作。UI 明示这是一版游戏的路径规则。硕士之后不能再读第二个硕士。

| 方案 ID | 展示 | 学期数 n | 一次性入学费用 fee | 主线事件顺序 |
| --- | --- | ---: | ---: | --- |
| `MS_1Y` | 再读一年硕士 | 2 | 8 | MASTER_01、MASTER_04 |
| `MS_2Y` | 再读两年硕士 | 4 | 12 | MASTER_01、MASTER_02、MASTER_03、MASTER_04 |

对每个方案分别计算：

```text
requiredReserve = fee + max(0, (cost - stipend) * n)
fundingEligible = money >= fee AND money - fee + stipend*n >= cost*n
```

在当前经济与特质配置下，`fundingEligible` 等价于 `money >= requiredReserve`。预算不计未来兼职、随机事件收入或未来可能被舍去的溢出资助，不借钱；界面显示当前资金、一次性费用、总资助、固定必要开销总额和至少需预留的钱。

普通特质的 LOW 至少需要钱 20/36；MID 需要 12/20；HIGH 需要 8/12，分别对应一年/两年。FRUGAL 用 cost=11 重算，不复用普通特质表。学业不足 55 或预算不足时该方案不可选并解释差额，不隐藏这个选项。

### 5.2 进入与继续

确认方案后**仅一次**扣 fee，记录 `mastersProgram`，保留四属性、全部本科标记、计数、个人愿望、家庭档案与特质。马上进入硕士第 1 学期，正常发放该学期资助，不重置为开局属性。

本科所有机会在选择硕士后视为放弃，不可留到硕士末再接受。本科快照与机会记录仍保留供回顾，但不影响后续抽签。硕士遵循同一投入/事件/期末循环，两个方案的同名事件含义与效果一致。

硕士事件不作独立毕业考试。完成最后学期视为完成硕士；不会再模拟不能毕业。预算资格覆盖明示的入学费和基础开销，不保障未来每次付费事件都负担得起，也不保证申博或求职结果。

`MASTER_04_A` 表示完成研究报告，`MASTER_04_B` 表示完成应用项目；两者都满足课程结束要求，两者互斥。一年与两年取得同等“完成硕士”资格加成；两年的额外价值来自多两个投入和事件，也伴随更多时间与开销，无额外时长概率奖励。

硕士最后一期结算后，冻结 MS 快照，重新判定三个机会。使用 MS 随机 key，保留本科结果但不复用。本次只能在三个取得的机会与 TRANSITION 中选择。

## 6. 毕业机会资格与经历变量

每次机会判定只读取相应毕业快照。前期 UI 可展示资格进度，正式概率以当前检查点最后一期全部结算后的值为准。

```text
A = academics; C = career
S = focusCounts.STUDY; J = focusCounts.CAREER
W = focusCounts.WORK; U = focusCounts.CAMPUS
s = min(S,4); j = min(J,4); w = min(W,3)
R = hasFlag(ARC_RESEARCH_3_A) ? 1 : 0
I = hasFlag(ARC_INTERNSHIP_3_A) ? 1 : 0
V = hasFlag(ARC_CREATIVE_3_A) ? 1 : 0
MR = hasFlag(MASTER_04_A) ? 1 : 0
MP = hasFlag(MASTER_04_B) ? 1 : 0
M = checkpoint == MS ? 1 : 0
```

R/I/V 分别是完成研究小项目、完成可展示的课程实践项目、完成可展示的作品；不是已取得录取/工作。支线第三幕 A 自身必须成立，不要求前两幕都 A。MR/MP 在 UG 恒为 0，在合法 MS 快照恰好一个为 1；R+I+V 在正常局中最多 2。变量由真实标记推导，不重复存同义状态。

| 机会 | 资格，任一条件即可 |
| --- | --- |
| `PHD` | `S >= 3 OR R == 1 OR MR == 1` |
| `LOCAL_JOB` | `J >= 2 OR I == 1 OR V == 1 OR MP == 1` |
| `HOME_JOB` | `J >= 1 OR W >= 2 OR S >= 2 OR U >= 3 OR R == 1 OR I == 1 OR V == 1 OR MR == 1 OR MP == 1` |
| `TRANSITION` | 始终可选，无资格和概率判定。 |

仅三次 STUDY、两次 CAREER 即可在不依赖支线抽取的情况下获得三种申请资格。属性不另设申请硬门槛：已有准备时，学业 49 与 50 都能申请，概率小幅变化。计数资格与硕士学业 55 门槛仍是公开的离散规则。

## 7. 概率公式与独立抽签

### 7.1 精确公式

仅对有资格的机会计算：

```text
rawPHD       = -25 + 0.90*A + 2*s + 12*R + 10*M + 6*MR
rawLOCAL_JOB =   8 + 0.80*C + 0.15*A + 2*j + 8*I + 5*V + 5*M + 5*MP
rawHOME_JOB  =  20 + 0.65*C + 0.20*A + 2*j + w + 4*I + 3*R + 3*V + 5*M + 5*MP
pPHD = clamp(floor(rawPHD + 0.5), 8, checkpoint == UG ? 85 : 95)
pJOB = clamp(floor(rawJOB + 0.5), 8, 95)
```

计数跨本科/硕士累计，但公式使用 cap 后的 s/j/w；CAMPUS 仅参与资格，不提供无上限概率奖励。学历 bonus 只加一次，不能按硕士学期数重复。

为避免浮点舍入误差，推荐将上式各项乘 100 计算整数 n：

```text
nPHD       = -2500 + 90*A + 200*s + 1200*R + 1000*M + 600*MR
nLOCAL_JOB =   800 + 80*C + 15*A + 200*j + 800*I + 500*V + 500*M + 500*MP
nHOME_JOB  =  2000 + 65*C + 20*A + 200*j + 100*w + 400*I + 300*R + 300*V + 500*M + 500*MP
p = clamp(floor((n + 50)/100), 8, correspondingCap)
```

所有概率是整数百分比，负的 raw 经过统一公式后限制到 8%。无资格的概率为 null，状态 INELIGIBLE，UI 写“准备尚不足”并列出资格路径，不写 0% 失败。

公式不再直接扣身心，不额外加入经济档、资金、家庭期待、愿望或隐藏运气项。身心通过投入效率影响积累，资助通过可承受安排影响历程。博士本科上限 85%、硕士上限 95%，两种工作上限 95%；较强准备仍保留小概率没有这次机会。

### 7.3 随机 key、临界值与冻结

使用 `06_ENGINE_AND_DATA_CONTRACT.md` 的 `draw01(seed,key)`，返回 [0,1)，固定 seed/key 永远相同。本文件不另造 PRNG。

| 检查点 | 固定读取顺序 |
| --- | --- |
| UG | `grad:UG:PHD`、`grad:UG:LOCAL_JOB`、`grad:UG:HOME_JOB` |
| MS | `grad:MS:PHD`、`grad:MS:LOCAL_JOB`、`grad:MS:HOME_JOB` |

每路分别满足 `eligible && roll01 < p/100` 才为 OFFERED；有资格未命中为 NOT_OFFERED。无资格也读取该路 key，但忽略结果，记 INELIGIBLE。三路独立，不排斥，不分配一个公共“中奖名额”。MASTERS 与 TRANSITION 不抽签。

例：概率 26/60/67，roll 为 0.25/0.60/0.20，取得博士与回国工作机会，美国工作未取得；等号判为未取得。因取得 HOME_JOB，本例不可选硕士。

每个检查点首次计算后保存快照、资格、概率、roll 与结果；刷新/重看不重抽。一年与两年硕士共用 MS 命名空间，因此同 seed 的同一路原始 roll 相同，额外学期改变的是准备而不是免费重试次数。

## 8. 去向选择与最终结果

每个检查点一次展示三种机会状态与具体概率（有资格时）。玩家从 OFFERED 去向中选一个，也始终可以选择 TRANSITION。本科时再加上符合第 5 节规则的硕士方案；未开放的方案显示原因。

不得自动替玩家接受最高概率或最“高级”的去向。没有任何机会且不能读硕士时，仍保留 TRANSITION，由玩家确认继续；没有机会但能读硕士时，可在读硕士和过渡期之间选择。

选择 TRANSITION，若当前检查点有任一 OFFERED，模式为 SELF_CHOSEN，否则为 NO_OFFER。硕士资格不算 OFFERED，放弃可选硕士但没有录取/工作仍为 NO_OFFER。NO_OFFER 叙事承认玩家也可能主动决定不再延长学习，不将其写成唯一被迫选择。

选择硕士会放弃 UG 机会；最终选择 PHD/LOCAL_JOB/HOME_JOB 必须是**当前检查点**的 OFFERED。PHD 另记录 entryMode：UG 为 `undergrad_direct`，MS 为 `masters_entry`。

选择最终去向后冻结终局，按 `07_ENDINGS.md` 组合文字，不再计算人生总分。钱或身心低不会撤销取得的机会；只通过结局模块描述当下压力。所有去向的五年后均不保证博士毕业、永久身份、财富或持续就业。
