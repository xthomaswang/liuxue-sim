# 产品设计与完成边界

## 一句话

《留学人生模拟器》是一款从高中最后一年开始、经过美国本科及有条件延续的硕士阶段的单人中文纯文字游戏：玩家选择家庭起点，准备大学申请，从同档次的三个真实大学 offer 中选一所，在有限资源下决定投入方向，最后由积累、经历与概率共同产生人生机会。

工作名：`liuxue_simulator`。游戏内暂用《留学人生模拟器》。名称不影响规则。

## 玩家应该得到的体验

1. 开局：我手里的条件很具体，能想象这个人为什么出国。
2. 途中：机会和资源有冲突；选了某件事，就要接受没有兼顾另一件事。
3. 回响：以前的决定会被人物记得，也会影响毕业机会。
4. 结尾：这是这一局走出来的人生，有所得，也有放下的部分。
5. 重开：换个家庭、重心或支线，我想看看会发生什么。

人生跨度要完整，生活细节用节点概括。高中最后一年只做两次选择，本科用八个节点表达；符合条件时继续一至两年硕士。整局默认路径目标6–9分钟，上限10分钟；博士入学就是博士结局，不继续模拟博士学习。没有逐日作息、体力倒计时或每天签到。

## 一局的完整流程

`生成三个家庭档案 → 选择档案与个人愿望 → 高中最后一年两次选择 → 按准备度与申请策略抽大学档次 → 同档三个真实大学offer中选一个 → 8 次本科循环 → 本科机会抽签 → 接受博士/工作机会，或进入过渡期，或在符合条件时继续硕士 → 硕士 2/4 次循环 → 硕士机会抽签 → 最终去向与五年后近况 → 重新开局`

每学期：获得家庭资助，选择一个投入重心，处理一个主线事件；如果该学期有支线，再处理一幕支线。随后结算固定支出、基础成长与消耗，展示学期回顾。

- 8 次投入重心选择。
- 8 个固定阶段的主线事件，每个两个选项。
- 6 个支线事件：两条不同支线各三幕，每幕两个选项。
- 高中2次＋本科22次生活决策；一年硕士另加4次，两年硕士另加8次，最长32次，不计家庭、学校、去向与确认操作。
- 整局含最长硕士路线也必须按10分钟内设计；目标6–9分钟。实际达标需真人试玩，当前文档不声称已实测。
- 没有途中 Game Over；经济或身心低谷产生代价和后续压力，仍能走到毕业结算。

## 八个节点

| 阶段 | 时间 | 叙事任务 | 支线槽 |
|---|---|---|---|
| S1 | 一年级秋 | 抵达、安顿、第一次把决定握在自己手里 | 无 |
| S2 | 一年级末 | 看见生活的实际成本，第一次调整预期 | A 第一幕 |
| S3 | 二年级秋 | 开始把时间投向某个圈子或方向 | B 第一幕 |
| S4 | 二年级末 | 暑期投入与资源机会成本 | A 第二幕 |
| S5 | 三年级秋 | 他人的进展带来比较，也逼近自己的问题 | B 第二幕 |
| S6 | 三年级末 | 把积累变成能向外展示的材料 | A 第三幕 |
| S7 | 四年级秋 | 申请、去留与对家人的说明 | B 第三幕 |
| S8 | 毕业前 | 告别、收尾，接受已经形成的人生轨迹 | 无 |

这里的“学期”是抽象生活节点。暑假可以写在春季末事件里，不增加额外行动轮。硕士事件见 `10_MASTERS_STORY.md`：一年依次玩节点 01、04；两年依次玩 01、02、03、04。硕士延续四属性、投入计数和历史，不再抽取新的支线。

硕士入口只有一次：本科两种工作机会都未取得，并满足学业与家庭延续资助要求。预算与学业具体门槛见 `03_SYSTEMS_AND_PROBABILITIES.md`。系统提供所有符合条件的 1 年/2 年方案，由玩家决定是否继续。已取得工作机会后主动拒绝工作，不开放首版硕士兜底；这是一条明确的版本范围规则。进入硕士会真正推进时间与消耗资源，也可能再次求职或申博未成。

| 部分 | 上限与规则 |

| 世界 | 美国、真实大学，全国学校目录＋统一玩法；按类别及来源粗分档，同档发3所offer |
| 开局 | 三种经济条件、三种家庭期待、六种个人特质，组合生成三个可选档案 |
| 个人愿望 | 三种，仅影响结局表达，不提供隐藏加成 |
| 主要状态 | money、academics、career、wellbeing，四条 0–100 数值 |

| 剧情 | 2个高中事件＋8个本科主线＋6条各3幕支线＋4个硕士事件＝32个完整事件、64个选项 |
| 常驻人物 | 林遥、艾达·洛文、许闻溪、周岚；家人用关系称谓 |

以上是首版封顶范围。32个事件在故事文件中完整提供，全部有默认短文和可展开长文。全国大学是数据范围，不要求为每校单独写剧情。学校目录的生产数据导入与分档核验见11，不把本设计包的示例名单当成已完成全国数据。

## 四个界面

1. **开局**：姓名（可选）、三个家庭档案、个人愿望。随后在同一文字界面完成高中两事件与同档三校offer选择。显示经济条件会影响资源难度，不伪装成所有背景等价。
2. **生活**：当前阶段、四属性、投入选项或事件、选项变化预览、结果文字、学期总结。人物信息通过正文带出，不做人物管理面板。
3. **毕业机会**：当前学历、资格状态、毕业快照、每条合格方向的实际概率、解释和一次“查看结果”。本科结果后还检查硕士资格，显示 1/2 年方案的预算；硕士结算没有再次续读硕士入口。
4. **人生回顾**：主去向、五年后片段、身心与资金近况、两条支线回响、个人愿望回应、可展开的概率记录、重新开始。

同一界面可以有不同 phase，不要求四个 URL 或独立路由系统。

## 纯文字呈现

- 文字具体、克制，生活中的温暖和荒诞都可以出现；不要每次选择都升级成励志宣言。
- 失去某种机会有真实遗憾，回国、休整、转向不等于人格失败。
- 故事前景是个人选择，家庭条件是真实的约束；不写“只要努力就一定成功”。
- 使用清楚的中文排版、留白、阶段标题和数值反馈；不制作图画，也不留待补图占位框。
- 默认事件35–65中文字，选后短结果15–35字；长文由玩家主动展开。详细阅读不强制，也不计为必须走完的额外步骤。
- 不做逐字动画、语音、结果弹窗、强制等待、大地图、角色捏脸或肖像生成。

## 防止范围失控

下面的题材允许出现在文本中，但不能单独形成首版系统：租房、社交、恋爱、健康、签证、城市旅行、公司经营、专业课程、家庭财务。

每增加一个独立状态，所有相关事件和结局都要考虑它。因此首版内容只通过现有四属性、投入计数和历史标记产生影响。历史标记是发生过什么的记录，不是第五、第六条可反复经营的资源。

新点子先写候选清单。完成首版前，只接受修复逻辑漏洞、提高可读性、改善明显失衡和替换不好玩的现有内容；不增加国家、角色路线、结局家族或卡组。真实学校名和有依据的分档不会自动赋予真实录取率、真实学费或毕业概率；它们的来源与游戏抽象在11中分开记录。

## 完成定义

- 在四种结局家族中都能走通至少一局；本科直博与硕士后入博有不同文案；一年和两年硕士路径均可完成。低资金和低身心也能继续。
- 同种子、同选择得到同结果；刷新不会重新抽结局。
- 2个高中、8个本科主线、18个支线和4个硕士事件都能正确加载，所有历史回响、资格和概率与规则一致。
- 高中选择能改变申请概率；每次给出的三所大学同档、不重复，玩家只能选择其中一所。
- 默认阅读路径包含最长硕士也能在10分钟内完成，结局页可立刻重新开局。
- 所有结果都有完整文案，没有占位的 TODO、乱码或无法继续的按钮。
- 新玩家不用开发者口头解释，能理解当前阶段、资源变化、为什么获得/没有获得某个机会。
- 经过小规模真人试玩，收集重玩意愿与不公平感；不把模拟通过等同于玩法已被验证。
