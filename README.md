# liuxue_simulator

**给 Claude 的完整设计交接包｜纯文字｜每局默认路径 10 分钟内｜2026-10-11**

本文件夹最初是一份设计与剧情文档（`docs/00`–`13`，事件正文、短文、选项、数值与历史标记以文档内 JSON 数组提供）。游戏已经按它实现，同一套代码提供三种形态：网站、iOS app、可在 Mac 上直接打开的 app。实现阶段新增的规则与相对原设计的偏离见 `docs/14`、`docs/15`。试玩后玩法改了两轮：第二版（开局抽天赋、每学期不同的安排与事件）见 `docs/16`–`21`；**现在的第三版照《人生重开模拟器》来——玩家只抽天赋、分配点数，其余全部自动模拟**，见 `docs/22`、`docs/23`。

在线试玩：<https://xthomaswang.github.io/liuxue-sim/>（推送到 `main` 后由 GitHub Actions 自动测试、构建并发布）。

## 运行与构建

需要 Node 24（`nvm use`）；iOS 与 Mac 版另需 Xcode。首次先 `npm install`。

| 想做的事 | 命令 | 说明 |
|---|---|---|
| 网站（开发） | `npm run dev` | 本地开发服务器 |
| 网站（构建） | `npm run build`，再 `npm run preview` | 产物在 `dist/`，是纯静态文件，可放到任何静态站点；没有自动部署 |
| Mac 版 | `npm run build:mac` | 产物 `build/LiuxueSim.app`，双击或 `open build/LiuxueSim.app`；本机 ad-hoc 签名，不能直接分发 |
| iOS 版（模拟器） | `npm run ios:sim` | 构建并在 iPhone 模拟器里启动；装真机要在 Xcode 打开 `apple/LiuxueSim.xcodeproj` 选自己的 Team，见 `apple/README.md` |
| 全部测试 | `npm test` | 规则、存档、界面、内容一致性、学校目录 |
| 真实 WebKit 冒烟 | `scripts/e2e-webkit.sh` | 用离屏 WKWebView 加载 `dist/` 自动点完几条完整路线并截图到 `build/e2e/` |
| 重新提取文案 | `npm run content:extract` | 改了 `docs/` 里的事件或文案后运行 |
| 重建学校目录 | `npm run schools:build` | 需要联网复核排名证据；`schools:build:offline` 只用缓存 |

代码结构：`src/engine`（纯函数规则引擎）、`src/content`（从文档提取的事件与文案、学校目录快照、结局卡文案）、`src/app`（存档与状态仓库）、`src/ui`（纯文字界面）、`apple/`（iOS 与 macOS 外壳，只负责加载 `dist/`）、`scripts/`（内容提取、学校目录管线、构建与冒烟脚本）、`data/schools/`（学校目录的来源、证据与报告）。存档在浏览器或 app 内置 WebView 的 localStorage 里，不联网、不上传。

## 已确定的游戏

从高中最后一年开始。先从三个随机家庭档案中选定起点，做高中准备与申请选择；根据申请准备程度和概率得到一个大学档次，再从同档随机给出的三个真实美国大学 offer 中选一所。

本科用八个节点走完四年，每局经历两条完整三幕支线。毕业机会由数值、实际经历与可复现概率决定。没找到工作、学业达到要求且家庭仍可负担时，可以继续一年或两年硕士，再求职或申博。本科直博或硕士后进入博士，均以博士入学结局收尾。

首版只有文字、数值和选择按钮，不做图片。包括最长硕士线，默认阅读路径目标6–9分钟，上限10分钟；完整长剧情和详细结局可主动展开。最终可重新开局。

## Claude 的阅读顺序

先读01、03、06、13、11，再读02和四份事件数据04/05/10/12，最后读07、08、09。00用于校验数据格式。

职责优先级：数值以03为准，申请档次以13为准，学校数据与分档以11为准，状态与随机接口以06为准，事件明确 effects 以事件数据为准。剧情描述不能自行发放录取、工作或隐藏加成。

## 当前状态与尚待验证的事

- 内容：第一版的 **32 个事件**，加上 16 张主线变体、16 张随机事件、46 张天赋（15 张需要解锁）、20 张学期安排、32 条突发小事，由脚本从文档提取，测试会检查生成文件与文档逐字一致。结局卡、25 个中途结局、36 个去向结局、38 条成就是手写的 JSON（`src/content/*.json`），加新梗只改数据、不动代码。
- 规则引擎保留了一个只给测试用的“经典模式”（不抽天赋、固定事件），继续与 Codex 留下的 Python 参考实现（`work/validate_design.py`）逐学期对拍一致；文档里的公式核对表、随机向量与可复核路线都有对应测试。
- 学校目录是**精选目录**，不是全国目录：综合大学前 200 左右、文理学院前 50、少量地区性大学与专门院校。其中一部分有可复核的 2027 版 U.S. News 名次，其余按近年榜单的大致区间分档，数据与界面里逐校区分。详见 `data/schools/README.md`。
- 所有资金、准备度、学校抽取、毕业概率与结局卡概率都是游戏参数，不是现实申请咨询或真实录取率。
- **真人试玩尚未进行**：十分钟时长、好玩程度与公平感都还没有真人数据，自动测试只能说明流程走得通。
- iOS 只在模拟器上验证过；Mac 版只在本机验证过。没有部署网站，也没有推送到任何远端。

设计文档在 `docs/`，Codex 的设计验证脚本与结果在 `work/`。
