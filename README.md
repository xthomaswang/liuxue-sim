# liuxue_simulator

**给 Claude 的完整设计交接包｜纯文字｜每局默认路径 10 分钟内｜2026-10-11**

本文件夹是设计与剧情文档，不是已经实现的游戏。全部交付文件为 Markdown；事件正文、短文、选项、数值与历史标记以文档内 JSON 数组提供，便于直接提取为游戏数据。

## 已确定的游戏

从高中最后一年开始。先从三个随机家庭档案中选定起点，做高中准备与申请选择；根据申请准备程度和概率得到一个大学档次，再从同档随机给出的三个真实美国大学 offer 中选一所。

本科用八个节点走完四年，每局经历两条完整三幕支线。毕业机会由数值、实际经历与可复现概率决定。没找到工作、学业达到要求且家庭仍可负担时，可以继续一年或两年硕士，再求职或申博。本科直博或硕士后进入博士，均以博士入学结局收尾。

首版只有文字、数值和选择按钮，不做图片。包括最长硕士线，默认阅读路径目标6–9分钟，上限10分钟；完整长剧情和详细结局可主动展开。最终可重新开局。

## Claude 的阅读顺序

先读01、03、06、13、11，再读02和四份事件数据04/05/10/12，最后读07、08、09。00用于校验数据格式。

职责优先级：数值以03为准，申请档次以13为准，学校数据与分档以11为准，状态与随机接口以06为准，事件明确 effects 以事件数据为准。剧情描述不能自行发放录取、工作或隐藏加成。

## 交付与尚待实现的边界

- 剧情设计包含 **32个完整事件、64个选项**，每个都提供默认短文和展开长文。
- 三位子代理分别完成世界/主线、六条支线、数值/结局，再由主代理整合状态机与跨文档规则。
- 高校目录采用全国数据驱动设计。本包有schema、分档规则、可核验样例与导入验收要求，**没有附上一份已清洗完成的全美院校数据库**；编码阶段须完成目录导入和来源核验，不能把少量示例包装成全国覆盖。
- 所有资金、准备度、学校抽取与毕业概率都是游戏参数，不是现实申请咨询或真实学校录取率。
- 自动校验和模拟检查设计一致性；游戏尚未编码，十分钟时长与好玩程度尚需实际试玩验证。
